
| `gasUsed` | **424,275** |
| `effectiveGasPrice` | **1,000,278 wei** (0.001000 gwei) |
| `l1Fee` (L1 데이터 수수료) | **19,060,015,684 wei** |
| **총계** | **443,452,964,134 wei = 0.0000004435 ETH** |

## 원화 환산

| | |
|---|---|
| ETH/KRW | **2,731,000원** — 업비트 `KRW-ETH`, 2026-07-29 22:24:03 KST |
| **커밋 1건** | **1.21원** |

내역:

| 항목 | 원 |
|---|---|
| L2 실행 (424,275 gas × 0.001 gwei) | 1.16 |
| L1 데이터 수수료 | 0.05 |

**L2 실행 가스가 비용의 96%다.** L1 데이터 수수료는 4%에 불과하다 —
GIWA가 L2라서 싼 것이 아니라 **가스 가격이 0.001 gwei로 낮기 때문**이다.

## 이전 문서의 「0.53원」은 틀렸다

기획 단계에서 `0.53원`이라고 적었는데 **실측의 절반 이하**다.
그때는 gas 사용량을 실제보다 낮게 잡았다. 지금은 발행된 트랜잭션의
영수증을 그대로 읽는다.

**제출 문서 전체를 1.21원으로 고쳤다.**

## 다시 계산하는 방법

```bash
TX=0x53dda9b6078f6bfb8874219509c50526b5661f3a139bab735ccd09ab97ab6225
curl -s -X POST https://sepolia-rpc.giwa.io -H 'content-type: application/json' \
  -d "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"eth_getTransactionReceipt\",\"params\":[\"$TX\"]}"
curl -s "https://api.upbit.com/v1/ticker?markets=KRW-ETH"
```

`gasUsed × effectiveGasPrice + l1Fee` 를 `1e18` 로 나누고 ETH 시세를 곱한다.

## 이더리움 L1과의 비교

같은 컨트랙트를 L1에 올린다면 **gas 사용량은 같다**(같은 바이트코드).
차이는 가스 가격뿐이다.

| | 가스 가격 | 커밋 1건 |
|---|---|---|
| GIWA Sepolia | **0.001000 gwei** (실측) | **1.21원** |
| 이더리움 메인넷 | **0.734 gwei** (실측) | **850원** |
| | | **약 702배** |

L1 가스 가격 출처: `eth_gasPrice` @ `ethereum-rpc.publicnode.com`, 2026-07-29 22:2x KST.

> **이 배수는 측정 시점의 값이다.** L1 가스 가격은 혼잡도에 따라 수십 배 움직인다.
> 0.734 gwei 는 낮은 편이므로 **혼잡할 때 배수는 더 커진다.**
> 우리는 지금 읽은 값만 쓴다.

## 아직 말할 수 없는 것

- **L1에서 실제로 발행해 보지는 않았다.** 위 L1 수치는 *실측 가스 사용량 × 실측 L1 가스 가격*
  이지, L1 영수증이 아니다. `l1Fee` 항목이 없어지는 등 세부는 다를 수 있다.
- **가스 가격은 네트워크 상황에 따라 변한다.** 위 값은 측정 시점의 0.001 gwei 기준이다.
- **테스트넷 수치다.** 메인넷 가스 가격 정책이 다를 수 있다.
