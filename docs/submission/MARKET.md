# 시장성 — 수요 근거

> **"지금 사용자가 몇 명인가"가 아니라 "수요가 실재하는가"를 다룬다.**
> GASOK 단계 구조상 초기 사용자 확보는 Phase 3(Market Readiness) 기준이고,
> Phase 1 의 시장성은 「실사용 수요와 성장 잠재력」이다.
>
> 아래는 전부 공개 출처다. 우리가 만든 수치는 하나도 없다.

---

## 1. 모수 — 한국 시장

| | |
|---|---|
| 가상자산 투자자 | **1,022만 명** (2026.02) |
| 거래 가능 이용자 | **1,133만 명** (2025년 말, 역대 최고) |
| 업비트 누적 회원 | **1,326만 명** (2025.12) |
| 업비트 20·30대 이용자 | **548만 명** — 전체 2030 인구의 **44%** |
| 업비트+빗썸 합산 점유율 | 약 **87%** |

**국민 5명 중 1명이 가상자산에 투자한다.** GIWA 는 그 시장의 지배적 거래소가 만드는 체인이다.

> 다만 증가율은 둔화 중이다 — 2024 하반기 24.7% → 2025 상반기 11% → 하반기 5.2%.
> **신규 유입이 아니라 기존 사용자의 신뢰 문제가 다음 단계의 병목**이라는 뜻이기도 하다.

---

## 2. 문제가 실재한다 — 규제가 증거다

한국은 **투자 조언의 신뢰 문제를 법으로 다루고 있다.**

- 2024년 8월 **자본시장법 강화 시행** — 대가를 받는 리딩방 운영이 불법이 됐다
- 대표 피해 유형: 수익률을 미끼로 가입 유도 후 무책임한 종목 추천,
  **업자가 미리 매수한 종목을 유료회원에게 고가 매도**
- 2025년 10월, **금감원이 유튜버와 협력**해 유사투자자문 피해 예방 캠페인을 시작했다

**규제와 캠페인이 필요할 만큼 문제가 크다.** 그런데 현재 대응은 전부 **사후 단속**이다.

POI 는 다른 층위에서 답한다 — **판단을 결과 전에 고정하고, 맞았는지를 컨트랙트가 계산한다.**
단속이 아니라 **증명 가능한 기록**으로 문제를 좁힌다.

> 이 시장에서 정직하게 조언하는 사람일수록 **자기를 구별할 수단이 없다.**
> 그게 POI 가 파는 것이다.

---

## 3. 비교 대상 — 이 카테고리는 이미 검증됐다

**TipRanks** (2012, 텔아비브) — 스스로를 **"Financial Accountability Platform"** 이라 부른다.

| | |
|---|---|
| 추적 대상 | 애널리스트 · 블로거 · 내부자 · 헤지펀드 매니저 **96,000명+** |
| 파트너십 | **Nasdaq**(2017) · E*TRADE(2016) · TD Ameritrade(2020) |
| 가격 | Premium **$359/년** · Ultimate **$599/년** |
| 창업 계기 | 창업자가 **잘못된 투자 조언으로 큰 손실**을 본 경험 |

**같은 문제에서 출발해 기관 파트너십까지 간 회사가 있다.** 수요는 가설이 아니다.

### POI 가 다른 지점

| | TipRanks | POI |
|---|---|---|
| 무엇을 추적하나 | **이미 공개된 기록**을 사후 수집 | 발행자가 **결과 전에 직접 고정** |
| 기록의 시점 | 플랫폼이 관측한 시점 | **온체인 커밋 시각** — 위조 불가 |
| 누가 들어가나 | 추적 가능한 매체의 전문가만 | **누구나** — 지갑만 있으면 |
| 정산 | 플랫폼이 계산 | **컨트랙트가 계산** — 플랫폼도 못 바꾼다 |
| 선택적 기록 | 막지 못함 | 「기한초과」로 **미발행이 드러남** |

TipRanks 는 **사후 수집**이라 구조적 한계가 있다 — 추적되지 않는 곳에서 한 말은 세지 않고,
플랫폼을 믿어야 하며, 본인이 원할 때만 들어간다.

**POI 는 그 세 가지를 프로토콜로 없앤다.**

---

## 4. 왜 지금, 왜 GIWA 인가

TipRanks 가 2012년에 못 한 것이 지금 가능해진 이유는 **저비용 체인**이다.

- 결정 하나를 그때그때 커밋하려면 **건당 비용이 사실상 0**이어야 한다
- GIWA 실측 가스 가격 기준 커밋 1건 ≈ **0.53원**
- 이더리움 L1 기준으로는 ≈ 5,040원 — **약 9,500배**

건당 5,000원이면 사람들은 판단을 묶거나 줄인다. 그 순간 시점 해상도가 무너지고
**"결과 전에 고정했다"는 증명 자체가 사라진다.** ([POI_v0.10.md](../POI_v0.10.md) §12.2)

그리고 **업비트 1,326만 회원**이 곧 검증 대상이자 검증자다.
POI 가 GIWA 위에 있어야 하는 이유는 기술이 아니라 **여기에 사람이 있기 때문**이다.

## 5. 첫 사용자와 검증 실험

**첫 10명**: 공개적으로 판단을 말하는 사람들 — 뉴스레터·리서치 작성자·투자 유튜버.

이들은 **이미 사후 검증 압력을 받고 있고**(금감원 캠페인이 그 압력의 증거다),
자기를 구별할 반박 수단이 없다.

### 30일 검증 실험

```
목표   10명이 각 3건 이상 커밋
관측   그중 절반 이상이 관측 구간 종료 후 결과를 등록하는가
```

**등록률이 낮으면 설계가 틀린 것이다** — 미발행 노출이 사용자에게 도움이 아니라
위협으로 작동한다는 뜻이고, 그때는 「기한초과」 표시 방식을 다시 봐야 한다.

가설을 확인하는 실험이지 성장 목표가 아니다.

## 6. 수익 가설 — 아직 검증되지 않았다

| | 대가 | 시점 |
|---|---|---|
| B2C 구독 | 저널 · 장기 리포트 · 외부 공유 프로필 | Phase 3 |
| Verification Fee | 제3자가 요청하는 정기 검증 · 갱신 | Phase 3 |
| B2B | 리서치 기관의 발행물에 신뢰도 부착 | 미검증 |

TipRanks 가 **$359~599/년**을 받는다는 사실이 지불 의사의 하한을 보여주지만,
**그건 그쪽 수치이지 우리 것이 아니다.**

지금 단계에서 수익화하지 않는다. 온체인 비용이 건당 0.53원이라 사용자 부담이 없고,
먼저 확인할 것은 **판단이 쌓이는가**다.

---

## 7. 정직하게 — 아직 없는 것

- **실사용자 0명.** MVP 단계이고, 초기 사용자 확보는 Phase 3 기준이다
- **인터뷰·대기자·LOI 없음.** 위 수요 근거는 전부 2차 자료다
- **한국 시장 기준.** 해외 확장 가설은 세우지 않았다
- **콜드스타트를 풀지 못했다.** 판단이 쌓여야 가치가 생기는데 초기에 쌓일 이유가 약하다.
  첫 10명 실험이 그 답을 찾는 과정이다
