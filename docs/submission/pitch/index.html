// 04 사용자

리서치를 쓰는 사람에게 무엇이 달라지는가

유료 뉴스레터를 운영하는 A. 구독자는 “이 사람 말이 맞았나”를 묻고, A 는 증명할 방법이 없다. — 실제 사용자가 아닌 가상 시나리오다.

지금

3월에 “반도체 조정 온다”고 썼다. 맞았다. 그런데 구독자에게 보여줄 게 지난 메일 캡처뿐이다.

경쟁자는 틀린 회차를 조용히 지운다. 지운 사람과 안 지운 사람이 화면에서 구별되지 않는다.

새 구독자는 결국 “요즘 잘 맞힌다더라”는 평판으로 고른다.

POI 이후

발행 전에 판단을 커밋한다. 내용은 해시로만 올라가 미리 스포일러가 되지 않는다.

구간이 끝나면 결과를 등록한다. 안 올리면 「기한초과」로 남는다 — 골라 기록하는 것이 화면에 드러난다.

구독자에게 링크 하나를 준다. 제3자가 직접 대조하고, 틀렸다고 보면 이의를 온체인에 남긴다.

왜 이게 가능한 문제인가 — 자본시장연구원은 투자의견이 “주관적 기준에 따른 정성적 정보라 사후적인 검증이나 비교가 매우 어렵다”고 지적한다. 검증을 어렵게 만드는 것은 데이터가 아니라 판단이 결과 이후에 수정 가능하다는 구조다.

if (d.windowStart < attestTime) revert WindowInPast();      // I4

그리고 지표 정의 문서의 바이트 해시가 온체인에 박혀 등록 즉시 frozen이다. 기준을 나중에 바꿀 수 없다.

// 08 왜 GIWA인가 ①

비용이 시점 해상도를 정한다

비용을 줄이려 커밋을 묶어도 절감은 기본가스뿐이라 약 17%에 그친다. 그리고 묶는 순간 같은 배치 안의 결정 선후 관계를 잃는다 — EAS 배치는 모든 attestation 에 같은 timestamp 를 넣기 때문이다(I2).

// 09 왜 GIWA인가 ②

새 신뢰 축을 세우지 않는다

EAS 프리디플로이스키마·발급·철회·참조를 재구현하지 않는다
도장 Verified Address「누가 말했는가」의 온체인 근거 — 연동 완료. 받아 본 것은 파우셋 발급분이고 KYC 경로는 미검증
저비용 L2결정 단위 커밋의 경제성
도장 Verified Balance머클 증명 — 잔고를 밝히지 않고 보유를 증명 (아직 쓰지 않음)

판단의 재료가 지갑에 있다. 누가 말했는가(Verified Address)는 연동했고, 그때 무엇을 들고 있었는가는 Verified Balance 의 머클 증명으로 붙일 수 있다. POI 의 술어 metricId·op·threshold 와 같은 모양이라 보자기가 오면 스키마 변경 없이 ZK 로 바뀐다.

// 12 실제 화면 ①

미발행이 그대로 드러난다

예상 결과를 선언해 놓고 결과를 올리지 않으면 인장이 「기한초과」로 바뀐다. 숨길 자리가 없다.

인장이 상태를 말한다

결과를 안 올린 판단은 「기한초과」로 남는다. 발행자가 지우거나 감출 수 없다.

누가 말했는지가 붙는다

발행자 주소 옆에 도장 검증 — TESTNET FAUCET. 검증 스냅샷 UID 도 함께 남는다.

커밋 당시 선언한 것이 그대로

지표·조건·관측 구간이 커밋 시각과 함께 남는다. 결과를 보고 나서 바꿀 수 없다.

화면이 검증 명령을 준다

같은 페이지 아래에 poi-verify 명령이 있다. 복사해 돌리면 MATCH 가 난다 — 우리 서버를 거치지 않는다.

// 13 실제 화면 ②

제3자가 이의를 온체인에 남긴다

관측값이 틀렸다고 보면 누구나 이의를 발행한다. 발행자가 지울 수 없다.

이의자는 정산자와 다른 주소다

같은 주소면 제3자 이의로 읽히지 않는다. 이의자가 검증 지갑인지도 함께 붙는다 — 화면의 「미검증 지갑」이 그것이다.

관측값과 출처를 같이 남긴다

90,688,000 · upbit-1m-candles(재계산) — 이의도 근거를 대야 한다. 제3자가 같은 절차로 다시 확인할 수 있다.

건수를 세지 않는다

지갑 생성 비용이 사실상 0 이라 개수는 언제든 부풀릴 수 있다. 목록만 보여주고 숫자를 만들지 않는다.

화면이 먼저 한계를 말한다

「조회된 것이 전부라는 보장은 없습니다」를 목록마다 표시한다. 보장 못 하는 것을 숨기지 않는다.

철회 이력도 남습니다 — 정산을 철회하고 정정하면 「이전 결과 등록(철회됨)」이 펼쳐진다. 결정 0xb1e46283…683b21
