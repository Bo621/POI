## Phase 1

### 01 GIWA 체인 적합성 — **9 / 10**

**근거**: §12.2 가 "왜 다른 체인이면 안 되는가"를 **수치와 코드로** 답한다.
비용 비교(1.21원 vs 850원)에 그치지 않고, 비용을 줄이려 할 때의 두 갈래와
각각의 대가를 밝힌다 — 트랜잭션 묶기는 I2(`ParentNotEarlier`)와 EAS 배치의
동일 timestamp 때문에 **결정 간 선후 관계를 잃고**, 집계 커밋은 개별 UID 가 사라져
정산·이의가 붙을 곳이 없어진다. 이건 "싸다"가 아니라 **구조적 논거**다.

EAS 프리디플로이·도장 위에 얹혀 자체 레지스트리를 만들지 않은 것도 실제 코드로 확인된다.

**도장 결합이 켜졌다** (2026-07-30). `verifiedSchemaUID = 0x072d75e1…6e08`(`bool isVerified`),
`verifiedIssuer = 0x09B170CA…49C6`(업비트 코리아). 컨트랙트가 **스키마와 발급자를 함께 확인**하므로
자기가 자기에게 발급한 attestation 은 검증 스냅샷이 될 수 없다(I18).

**도장 경로가 온체인으로 증명된다.** 검증 지갑으로 발행한 결정이 fixture 에 있고
(`0x3f592f21…6938`), 화면에 「도장 검증 — TESTNET FAUCET」으로 표시된다.
발급자를 **집합**으로 두고 라벨을 온체인에 남겨, 업비트 KYC 와 테스트 파우셋을 구별한다.

**감점**: 지금 붙은 것은 **테스트넷 파우셋 검증**이지 업비트 KYC 가 아니다.
업비트 코리아 발급자도 등록해 뒀지만, 일반 사용자가 그 검증을 받는 공개 경로가
아직 없다(GIWA 문서에도 안내가 없다). **KYC 결속 신원은 여전히 미증명**이다.

### 02 독창성 — **8 / 10**

**근거**: "관측 구간을 과거로 못 잡는다(I4)" + "정산 산술을 컨트랙트가 재계산한다(I17)" +
"지표 정의를 문서 바이트 해시로 고정한다" 셋의 조합은 본 적이 없다.
특히 **미발행을 「기한초과」로 드러내는 것**과 **이의 건수를 세지 않는 것**은
"안 만든 것이 만든 것만큼 중요하다"는 설계 태도를 보여준다.

**감점**: 개별 요소는 전부 기존 기술이다. EAS 로 직접 만들면 구현 가능하고,
문서도 그렇게 인정한다(정직하지만 독창성 점수에는 불리하다).
**진짜 신규성은 도메인 스키마 설계에 있는데, 그건 심사자가 알아보기 어렵다.**

### 03 실현 가능성 — **10 / 10**

**근거**: 테스트넷에 **이미 배포돼 동작한다.** 컨트랙트 4종 Verified,
fixture 3종이 살아 있고, 공개 URL 에서 지갑 없이 조회·검증이 된다.
일반 사용자 지갑으로 커밋 → 정산 → `poi-verify MATCH` 까지 실제로 돌았다.

"만들 수 있다"가 아니라 **"만들었다"**를 심사자가 직접 확인할 수 있다.

### 04 시장성 — **7 / 10** *(1차 채점 5점에서 정정)*

> **1차 채점이 틀렸다.** "실사용자 0명"을 감점 사유로 썼는데, GASOK 단계 구조상
> **초기 사용자 확보는 Phase 3(Market Readiness) 기준**이다.
> Phase 1 의 시장성은 「실사용 수요와 성장 잠재력」 — *지금 사용자가 있느냐*가 아니라
> *수요가 실재하느냐*를 묻는다. 기준을 잘못 적용했다.

**근거** ([MARKET.md](MARKET.md)):
- **모수** — 가상자산 투자자 1,022만 명, 업비트 누적 회원 1,326만 명,
  업비트 20·30대 548만 명(2030 인구의 44%). **국민 5명 중 1명**
- **문제가 실재한다는 증거가 규제다** — 2024.08 자본시장법 강화로 유료 리딩방이 불법이 됐고,
  2025.10 금감원이 유튜버와 협력해 피해 예방 캠페인을 시작했다.
  **규제가 필요할 만큼 크지만 대응은 전부 사후 단속이다**
- **카테고리가 이미 검증됐다** — TipRanks 는 스스로를 "Financial Accountability Platform"
  이라 부르고, 전문가 96,000명+ 를 추적하며 Nasdaq·E*TRADE·TD Ameritrade 와 제휴했다.
  가격은 $359~599/년. **같은 문제에서 출발해 기관까지 간 회사가 있다**
- **POI 의 차별점이 명확하다** — TipRanks 는 *사후 수집*이라 추적 안 되는 곳의 말은 못 세고,
  플랫폼을 믿어야 하며, 본인이 원할 때만 들어간다. POI 는 셋 다 프로토콜로 없앤다

**감점**:
- 수요 근거가 **전부 2차 자료**다. 인터뷰·대기자·LOI 가 없다
- "누가 돈을 내는가"의 답이 전부 Phase 3 다. TipRanks 가격은 **그쪽 수치이지 우리 것이 아니다**
- **콜드스타트를 풀지 못했다** — 판단이 쌓여야 가치가 생기는데 초기에 쌓일 이유가 약하다

### 05 팀 구성 역량 — **8 / 10**

**근거**: 1 인이 컨트랙트·프론트·검증기·문서를 전부 만들었고 결과물이 있다.
경력이 문제와 정확히 맞물린다 — 펀드 기준가 산출, 운용 성과 정산 0→1,
NFT 낙찰 대금 분배·원장 대사, 거래소 FDS. **10 년을 프로토콜로 옮긴 것**이다.

**감점**: **1 인이다.** 5 개월 프로그램에서 혼자 메인넷까지 가는 건 위험하고,
백엔드는 "합류 예정"으로 확정되지 않았다. 심사자는 버스 팩터를 본다.

### 06 GIWA 월렛 내 탑재 가능성 — **6 / 10**

**근거**: 구조가 유리하다 — 백엔드 없음, 해시 라우팅, EIP-1193 만 요구,
조회는 지갑 없이 동작, 트랜잭션 건당 1.21원 · 서명 1회.
EIP-6963 을 구현해 지갑이 여럿일 때도 정상 동작한다.

**감점**: **검증된 적이 없다.** 문서도 "탑재 후보 구조"라고만 쓴다.
월렛 임베드 규격을 모르니 실제로 담길지 알 수 없고, 이 기준은 GIWA 팀이
직접 판단할 영역이라 우리가 점수를 만들 수단이 거의 없다.

## Phase 2

### 07 실제 구현 수준 — **9 / 10**

**근거**: 네 상태(기한초과 · 등록완료+제3자 이의 · 철회→정정 · 대기)가
테스트넷에 **동시에 살아 있다.** 심사자가 링크를 눌러 바로 본다.
오프체인 검증기가 업비트 공개 데이터로 관측값을 재계산해 온체인과 대조한다.

**감점**: 노트→결정 승격과 Decision Graph 는 구현·배포됐는데 **fixture 가 없다.**
심사자가 화면에서 볼 수 없는 기능이 남아 있다.

### 08 기술 완성도 — **8 / 10**

**근거**: 불변식이 코드에 번호로 표시돼 있고 포크 테스트가 **실제 EAS 바이트코드**를
상대로 돈다. commitment 테스트 벡터를 Solidity 와 TS 가 **같은 파일**에서 읽어
구현이 갈라지면 테스트가 먼저 깨진다. 비정규 payload 를 재인코딩 대조로 막는다.
테스트 422 개.

**감점**:
- ~~소유권이 아직 배포 지갑에 있다~~ → **2-of-2 Safe 로 이전 완료** (2026-07-30).
  다만 **두 키를 같은 사람이 보유**하므로 단일 키 위험 제거이지 권한 분산은 아니다
- 지표가 2 종뿐이다
- **개발 중 잡은 결함 8 건이 전부 단위 테스트를 통과하고 있었다** —
  테스트 개수가 품질을 보증하지 못한다는 증거다. 정직하게 적었지만 감점 요인이다

## 내가 심사자라면 — 선발한다. 다만 조건부다

**선발 이유**: Phase 2 기준(실제 구현 수준 · 기술 완성도)에서 상위권이다.
말이 아니라 **동작하는 것**을 가져왔고, 심사자가 5 분 안에 직접 확인할 수 있다.
GIWA 적합성 논거도 "싸다"가 아니라 구조적이다.

**조건**: 콜드스타트 해법과 팀 규모가 프로그램 5 개월을 버틸지 의문이다.

## 떨어뜨린다면 이유 셋

1. **콜드스타트를 풀지 못했다** — 수요는 있는데 첫 사용자를 어떻게 모을지가 가설뿐이다
2. **1 인 팀** — 메인넷·데모데이까지 5 개월을 혼자 가는 건 위험하다
3. **월렛 탑재가 미검증** — GIWA 가 이 기준을 중요하게 본다면 우리는 답이 없다

## 지금 고치면 점수가 오를 것 셋

1. **뉴스레터 작성자 3~5 명에게 실제로 커밋하게 한다** — 04 시장성이 7 → 9.
   2차 자료가 아니라 **우리 사용자의 행동**이 근거가 된다
2. **Decision Graph fixture 를 만든다** — 부모-자식 결정 2~3 건.
   07 구현 수준이 9 → 10 이 되고, "판단이 이어진다"는 핵심 서사가 화면에 보인다
3. ~~**소유권을 multisig 로 옮긴다**~~ — **완료했다.** 08 기술 완성도가 8 → 9.
   지금은 "혼자 지표를 추가할 수 있다"가 그대로 남아 있다
