## 2. 장별 주의점 — 틀리기 쉬운 곳

### 06 무엇이 강제되나 (압축)

GASOK 덱은 `I4`·`I17`·`I2` 코드 세 줄을 보여줍니다. **일반 심사자에게는 과합니다.**
「무엇을 못 하게 막는가」 세 줄로 바꾸세요.

```
관측 구간을 과거로 못 잡는다      지나간 구간을 골라 「맞혔다」 할 수 없다
정산 산술을 컨트랙트가 강제한다   발행자가 결과를 정할 수 없다
지표 정의가 고정돼 있다           나중에 기준을 바꿀 수 없다
```

코드는 부록이나 발표 때 질문받으면 보여주세요.

### 10 경쟁 · 11 차별점

**Kaito 사례를 반드시 넣으세요.**

> Kaito 는 2026년 1월 X 가 API 접근을 차단하며 주력 제품 Yaps 를 종료했습니다.
> POI 는 X API 를 쓰지 않습니다 — KOL 이 **스스로 온체인에 커밋**하는 구조라
> 끊길 API 가 없습니다.

경쟁자가 플랫폼 의존으로 무너진 사례는 **차별점을 설명하는 가장 빠른 방법**입니다.

| | 무엇을 재나 | 방식 |
|---|---|---|
| TipRanks | 애널리스트 정확도 | 공개 의견을 **긁는다** (사후 관찰) |
| Kaito | 관심도(mindshare) | X API 의존 → **차단당함** |
| Cookie3 | 온체인 어트리뷰션 | 캠페인 성과 |
| 인간지표 | 유튜버 발언 | 제3자 관찰 · 스스로 「가상·재미」 |
| **POI** | **본인이 사전에 고정한 판단** | **본인 커밋 · 컨트랙트 판정** |

### 13 시장 크기 — 국내 수치를 앞세우지 마세요

```
❌  국내 유사투자자문 8,900억     → "그런데 왜 글로벌?" 이라는 반문을 부름
✅  Substack 작가 수익 $450M/년 · 유료 구독 500만
    최고가 4개 중 3개가 금융 (Citrini $1,200/년)
    TipRanks ARR $20~30M · 2024년 $200M 규모 인수
```

국내 수치는 **「문제가 실재한다」의 근거(03장)**로만 쓰고,
**시장 크기는 글로벌로** 잡으세요. 목적이 다릅니다.

### 16 BEP — 낙관치를 쓰지 마세요

```
월 고정비 (2인)  약 950만원
BEP 조건        B2B 연 $20K × 5곳  또는  B2C $5/월 × 1,400명
도달 목표       12~18개월
전제            6개월 안에 공급 100명
```

**전제를 명시하는 게 핵심입니다.** 「12개월 BEP」만 쓰면 근거 없는 낙관으로 읽히고,
전제를 함께 쓰면 계산을 한 사람으로 읽힙니다.

### 17 팀 — 1인을 숨기지 마세요

GASOK 덱에서는 팀을 뺐지만 **여기서는 필수**입니다. 방문·발표평가에서 기업가 정신을 봅니다.

직전 제품 실패를 **먼저** 쓰세요.

> 거래소 자산 통합 조회 서비스를 만들었고, 6개 거래소를 연동했고, 국책 R&D 1.2억을
> 수행 완료했습니다. 그런데 **국내 거래소 약관이 서브파티 접근을 금지**한다는 것을
> 직접 확인하고 런칭을 접었습니다.
>
> POI 는 그 경험에서 나왔습니다 — **거래소 데이터에 의존하지 않고도 성립하는 구조**입니다.

「실패했다」가 아니라 **「부딪혀 보고 배워서 방향을 바꿨다」**로 읽힙니다.
그리고 이건 사실이라 발표에서 흔들리지 않습니다.

### 19 수요 검증 결과 — 가장 중요한 장

**독립 채점 둘이 같은 곳을 지목했습니다** — 실제 사용·결제로 확인된 수요가 없다는 것.
이 장이 비면 나머지가 아무리 좋아도 떨어집니다.

인터뷰 결과가 나오는 대로 채우세요. 형식은 이렇게:

```
크립토 KOL   N명 인터뷰 · M명이 그 자리에서 온체인 커밋
수요측       N곳 인터뷰 · 파일럿 승낙 M건 / 예산 권한자 소개 M건
직접 인용    "…" — 실제 발언 그대로 (익명 처리)
```

**숫자가 작아도 씁니다.** 「8명 중 3명이 즉석에서 커밋했다」가
「많은 관심을 확인했다」보다 100배 강합니다.

### 23 자금 사용 계획 — 채용을 병목 해소로

```
❌  개발자 1명 채용
✅  POI 의 다음 병목은 컨트랙트가 아니라 오프체인입니다.
    검증기를 상시 서비스로 만들고, 조회 API 를 열고, 인덱서로 RPC 한계를 넘는 일.
    그 API 가 첫 수익 경로(KOL 검증 API)의 전제입니다.
    백엔드 10년차 · 스마트컨트랙트 경매 시스템 구축 경험자와 합류를 논의 중입니다.
```

채용비가 **비용이 아니라 매출 전제**로 읽힙니다.

### 24 접는 기준 — 넣을지 판단이 필요합니다

```
3개월   발행자 10명이 각 3건 이상 커밋
6개월   유료 의사를 밝힌 기관 1곳
12개월  MRR 100만원
```

**두 가지로 읽힐 수 있습니다.**

- 긍정 — 기준을 정하고 들어가는 사람. 직전 실패 경험이 학습으로 이어졌다는 증거
- 부정 — 자기 아이템에 확신이 없다

**넣는 쪽을 권합니다.** 직전 제품 실패를 이미 밝힌 맥락에서는 일관되고,
방문·발표평가에서 경험 많은 심사자에게는 **성숙함**으로 읽힐 확률이 높습니다.
다만 제목을 「접는 기준」이 아니라 **「검증 마일스톤」**으로 쓰세요. 같은 내용, 다른 인상입니다.

## 3. 방문평가 — 여기가 최대 강점입니다

재단 실무자가 **직접 찾아옵니다.** 그 자리에서 할 수 있는 것:

```
1  공개 URL 을 연다 — 지갑 없이 열린다
2  결정 하나를 보여준다 — 조건 「> 90,000,000」, 관측값, 컨트랙트 판정
3  터미널에서 검증기를 돌린다 — MATCH · 종료코드 0
4  익스플로러에서 컨트랙트 소스 검증을 보여준다
```

**5분이면 「진짜 만들었다」가 증명됩니다.** 대부분의 시드 지원자가 못 하는 것입니다.
발표 자료보다 이 시연을 준비하는 데 시간을 더 쓰세요.

*단 업비트 공개 API 에 레이트 리밋이 있습니다. 시연 직전에 한 번 돌려 보고,
`429` 가 나면 `--no-fetch` 로 온체인만 보여주는 경로를 준비해 두세요.*
