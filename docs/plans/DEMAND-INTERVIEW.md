# 수요 검증 인터뷰 — 질문지와 판별 기준

> **목적은 「좋은 아이디어네요」를 듣는 것이 아니라, 그 말을 걸러내는 것입니다.**
>
> 독립 채점 둘이 같은 곳을 지목했습니다 — *실제 사용·결제로 확인된 초기 수요가 없다.*
> 이 문서는 그 하나를 메우기 위한 것입니다.

---

## 0. 원칙 — 이것만 지키면 절반은 성공

| 하지 말 것 | 대신 물을 것 |
|---|---|
| 「이런 서비스 쓰시겠어요?」 | 「**지난번에는** 어떻게 하셨어요?」 |
| 「얼마면 사시겠어요?」 | 「**지금 그 문제에 얼마를 쓰고** 계세요?」 |
| 제품 설명 먼저 | 상대 이야기 먼저. 제품은 마지막 5분 |
| 「좋다」는 반응 수집 | **다음 행동**을 받아 내기 |

**미래 가정형 질문의 답은 전부 무효입니다.** 사람은 미래의 자기 행동을 정확히 예측하지 못하고,
상대를 실망시키지 않으려 합니다. **과거에 실제로 한 일**만 데이터입니다.

---

## 1. 대상 A — 크립토 KOL (공급측)

**확인할 것: 사전 커밋이라는 행동 변화를 받아들이는가.**
POI 의 최대 리스크가 여기입니다. 이 사람들이 안 모이면 나머지는 전부 무의미합니다.

### 질문 순서 (30분)

**① 현재 행동 — 15분**

1. 최근에 공개적으로 낸 전망 중 **가장 기억에 남는 것**이 뭔가요? 왜요?
2. 그게 맞았는지 **나중에 확인해 본 적** 있으세요? 어떻게요?
3. 새로 온 사람이 「이 사람 말이 맞나」를 물으면 **뭘 보여주세요?**
4. 지금까지 낸 전망을 **모아 둔 곳이 있나요?** (있으면 보여 달라고 하기)
5. 전망을 **지우거나 수정한 적** 있으세요? *(직접 묻지 말고: 「다들 틀리면 어떻게 하던가요?」로 우회)*

**② 통증 확인 — 10분**

6. 「저번에 틀렸잖아」라는 말을 **들어 본 적** 있나요? 그때 뭐라고 답하셨어요?
7. 실적을 증명하려고 **돈이나 시간을 써 본 적** 있나요? (편집, 아카이브, 대행)
8. 프로젝트나 브랜드에서 섭외가 올 때, **뭘 근거로 고르는 것 같던가요?**

**③ 즉석 테스트 — 5분  ← 여기가 핵심**

> 「지금 5분이면 됩니다. **오늘 생각하시는 전망 하나를 지금 커밋해 보시겠어요?**
>  결과는 나중에 자동으로 붙습니다. 틀려도 그대로 남습니다.」

**이게 진짜 시험입니다.** 「쓰겠다」는 말 100개보다 **지금 한 건 커밋하는 행동 하나**가 큽니다.

## 2. 대상 B — Web3 프로젝트 마케팅 담당 (지불측)

**확인할 것: 돈을 쓸 예산과 권한이 있는가, 그리고 이 문제에 이미 쓰고 있는가.**

### 질문 순서 (30분)

**① 현재 지출 — 15분**

1. 최근 KOL 캠페인을 **몇 건** 하셨어요? 예산은 대략 어느 규모였나요?
2. KOL 을 **어떻게 고르세요?** 마지막에 고른 사람은 왜 골랐어요?
3. 캠페인 끝나고 **성과를 어떻게 판단**하세요?
4. 지금 쓰는 도구가 있나요? (Kaito, Cookie3, 대행사 등) **얼마 내세요?**
5. 섭외했다가 **후회한 적** 있나요? 뭐 때문에요?

**② 통증의 크기 — 10분**

6. 그 후회로 **날린 돈이 얼마쯤** 되나요?
7. 「이 사람이 과거에 실제로 맞혔는지」를 **확인할 방법을 찾아본 적** 있으세요?
8. 못 찾으면 **어떻게 결정**하세요?

**③ 다음 행동 요청 — 5분  ← 여기가 핵심**

셋 중 하나를 **반드시** 요청합니다.

| 요청 | 무게 |
|---|---|
| 「다음 캠페인 때 **파일럿으로 한 번** 써 보시겠어요?」 | **가장 강함** |
| 「예산 결정하시는 분을 **소개해 주실 수 있나요?**」 | 강함 |
| 「2주 뒤에 **초안 보여 드려도** 될까요?」 | 약함 |

**아무 요청도 안 하고 끝낸 인터뷰는 데이터가 아닙니다.**

## 3. 신호 판별 — 진짜와 예의상

### ❌ 무효 — 세어도 의미 없음

```
"좋은 아이디어네요"
"필요할 것 같아요"
"출시하면 알려주세요"
"쓸 것 같은데요"
"얼마면 살 만할 것 같아요"      ← 가정한 가격은 가격이 아님
"우리 팀에 공유해 볼게요"        ← 후속이 없으면 거절과 같음
```

이 답만 받았다면 **그 인터뷰는 실패**입니다. 질문이 잘못됐다는 뜻이니 다음 사람에게 고쳐 물으세요.

### ✅ 유효 — 이건 데이터

```
과거 지출     "그거 때문에 대행사에 월 300 썼어요"
과거 행동     "엑셀로 직접 모아 뒀어요" (실물을 보여 줌)
구체적 손실   "지난번에 섭외 잘못해서 2,000만원 날렸어요"
현재 대체재   "지금은 Kaito 로 보는데 그건 관심도지 정확도가 아니에요"
자발적 다음   상대가 먼저 "언제 보여줄 수 있어요?"를 물음
소개          예산 권한자를 실제로 연결
즉석 행동     KOL 이 그 자리에서 커밋함
```

### 판별 한 줄

> **상대가 이미 그 문제에 돈·시간·평판을 쓴 증거가 나오면 진짜입니다.
> 앞으로 쓰겠다는 말만 나오면 예의입니다.**

## 4. 기록 양식 — 인터뷰마다 이것만

```
일시 / 대상 / 유형(KOL · 프로젝트)

이미 쓰고 있는 돈·시간     [금액 · 대상 · 근거가 되는 발언 그대로 인용]
지금 쓰는 대체 수단         [없으면 "없음" 이라고 적을 것]
가장 아팠던 구체 사건       [금액·시점이 있으면 반드시]
요청한 다음 행동            [무엇을 요청했나]
받은 답                     [승낙 / 회피 / 거절]
실제 후속                   [일주일 뒤 채울 것 — 여기가 진실]

내 판정   진짜 수요 / 예의 / 판단 불가
```

**「실제 후속」 칸이 가장 중요합니다.** 승낙해 놓고 답이 없으면 그건 거절입니다.

## 5. 목표와 통과 기준

| | 목표 | 통과 기준 |
|---|---|---|
| **KOL** | 8명 인터뷰 | **3명이 즉석에서 커밋** |
| **프로젝트** | 5명 인터뷰 | **1곳이 파일럿 승낙 또는 예산자 소개** |

### 결과별 해석

| 결과 | 뜻 | 다음 |
|---|---|---|
| KOL 커밋 3+ · 프로젝트 승낙 1+ | **수요 있음** | 지원서에 그대로 씀. BM 항목이 채워짐 |
| KOL 커밋 3+ · 프로젝트 0 | 공급은 되는데 **돈이 안 보임** | 지불 주체를 다시 찾아야 함 |
| KOL 커밋 0~1 | **행동 변화가 안 일어남** | 가장 나쁜 신호. 대상을 AI 에이전트로 바꿔 재시도 |
| 양쪽 다 0 | 지금 형태로는 수요 없음 | 접거나 근본적으로 다시 |

## 6. 일정

```
1~2일차   대상 리스트 15명 (KOL 8 · 프로젝트 5 · 예비 2)
          X · 텔레그램 · 디스코드로 접촉. "30분만" 이라고 요청
3~5일차   인터뷰 실행 · 기록
6일차     판정 · 지원서에 반영
7일차 이후 후속 확인 (승낙이 실제 행동으로 이어졌는지)
```

**인터뷰는 영어로 하게 됩니다.** 글로벌 타겟이니 이 자체가 「영어권에서 실행 가능한가」의 첫 시험이기도 합니다.
