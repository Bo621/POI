## W9 — `dag.tsx` + `graph.ts` (F9)

decisionUID를 넣으면 **부모 방향으로** 그래프를 따라간다.

### `graph.ts` — 순수 함수

```ts
export interface DagNode {
    uid: Hex; attester: Hex; time: bigint; depth: number;
    parents: Hex[]; missing: boolean;      // 조회 실패·미발견
}

/** 너비 우선. maxDepth 기본 3, 노드 상한 기본 64 */
export function buildDag(
    root: Hex,
    fetchParents: (uid: Hex) => Promise<{attester: Hex; time: bigint; parents: Hex[]} | undefined>,
    opts?: {maxDepth?: number; maxNodes?: number},
): Promise<DagNode[]>;
```

- **중복 방문 금지** — 같은 UID를 두 번 넣지 않는다(DAG는 합류할 수 있다).
- 조회 실패한 부모는 `missing: true`로 **남긴다.** 조용히 빼면 그래프가 거짓이 된다.
- `maxNodes`에 도달하면 멈추고, 잘렸다는 사실을 호출자가 알 수 있게
  마지막에 `truncated` 플래그를 반환한다(반환 타입을 `{nodes, truncated}`로).
- 재귀 대신 큐를 쓴다. 깊은 체인에서 스택이 터지지 않게.

### `dag.tsx`

- 깊이별로 들여쓰기한 목록. **그래프 라이브러리를 도입하지 말 것** — 목록으로 충분하고
  범위 밖이다. 들여쓰기는 `padding-inline-start: calc(depth * 1.25rem)`.
- 각 노드: UID(축약, mono) · attester(축약) · 시각 · 부모 수
- `missing` 노드는 `.doc-note`로 `"조회하지 못했습니다"`
- **상시 표시**(§10 인덱서 누락): `"조회된 것이 전부라는 보장은 없습니다."` `.notice--quiet`
- `truncated`면 추가로 `"노드 상한에 도달해 일부만 표시합니다."`

### 테스트 — `graph.test.ts`

| # | 내용 |
|---|---|
| 1 | 부모 없는 단일 노드 → 노드 1개, depth 0 |
| 2 | 선형 체인 3단 → depth 0·1·2 |
| 3 | 합류(두 부모가 같은 조부모) → 조부모가 **한 번만** 나온다 |
| 4 | 순환 입력(A→B→A, 실제로는 불가능하지만 방어) → 무한루프 없이 끝난다 |

| 6 | `maxNodes: 2` → `truncated === true` |
| 7 | 부모 조회 실패 → 그 노드가 `missing: true`로 **남는다** |

## W10 — `passport.tsx` (F10)

한 지갑의 결정·정산을 요약한다. **랭킹·점수·집계 수치를 만들지 말 것** —
이의 건수 미표시와 같은 이유(Sybil)이고, POI는 순위 제품이 아니다.

주소를 입력받아 EAS `Attested` 로그를 결정 스키마로 조회해 그 attester의 것만 남긴다.

표시 항목(결정 하나당 한 줄, `.doc-fields`):

```
UID(축약) · 커밋 시각 · 상태 인장 문구(텍스트로, 도장은 그리지 않는다) ·
등급 2축 · 예상 결과 선언 여부
```

- **정렬은 커밋 시각 내림차순 하나만.** 정렬 컨트롤을 주지 않는다.
- 합계·평균·적중률을 **계산하지 않는다.** 화면에 숫자 요약을 두지 않는다.
  상단에 `.notice--quiet`로 한 줄:
  `"이 목록은 조회된 기록의 나열입니다. 순위나 성과 지표가 아닙니다."`
- `"조회된 것이 전부라는 보장은 없습니다."`도 상시 표시.

순수 함수로 분리해 테스트한다:

```ts
export function sortByCommittedAtDesc(rows: PassportRow[]): PassportRow[];
export function summarizeRow(row: PassportRow): {label: string; grade: string};
```

| 테스트 | |
|---|---|
| 정렬이 시각 내림차순 | 같은 시각이면 입력 순서 보존(안정 정렬) |
| `summarizeRow`가 7상태 문구와 2축 등급을 준다 | |
| **집계 함수가 존재하지 않는다** | `passport.tsx`에 `reduce(`·`평균`·`적중`·`승률` 문자열이 없다 |

마지막 항목은 실제 테스트로 쓴다 — 소스를 읽어 금지 문자열이 없는지 확인한다
(`errors.test.ts`가 `contracts/src`를 읽는 방식과 같다).
