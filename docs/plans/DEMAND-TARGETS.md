## 0. 먼저 — 경쟁자에게서 배운 것

```
2026-01   X 가 「포스팅 보상 앱」의 API 접근을 차단
          → Kaito 가 Yaps 와 인센티브 Yapper Leaderboard 를 종료
```

**Kaito 는 플랫폼 의존 때문에 주력 제품을 잃었습니다.** POI 는 X API 를 쓰지 않습니다 —
KOL 이 **스스로 온체인에 커밋**하는 구조라 끊길 API 가 없습니다.

인터뷰에서 이 이야기를 꺼내면 상대가 문제를 빨리 이해합니다.
지원서의 「경쟁 우위」 항목에도 그대로 씁니다.

## 1. KOL 8명 — 누구를 겨눌 것인가

### 티어 설계

| 티어 | 팔로워 | 응답률 | 대표성 | 판단 |
|---|---|---|---|---|
| 초대형 | 50만+ | 매우 낮음 | 높음 | **제외** — 답을 안 함 |
| **중견** | **1만~10만** | **중간** | **높음** | **주력 6명** |
| 신진 | 1천~1만 | 높음 | 낮음 | 보조 2명 |

**중견층이 핵심입니다.** 이들은 평판을 쌓는 중이라 **증명 수단이 실제로 필요**하고,
DM 도 열려 있습니다. 초대형은 이미 평판이 있어 POI 가 필요 없고 답도 안 합니다.

### 선별 필터 — 여기가 제일 중요합니다

역선택 때문에 **아무 KOL 이나 만나면 안 됩니다.** 이 조건을 통과하는 사람만 만나세요.

| 필수 | 확인 방법 |
|---|---|
| **반증 가능한 전망을 낸다** | 「BTC 가 X 를 넘는다」처럼 **숫자와 기한**이 있는 글. 「강세장 온다」류는 제외 |
| **틀린 것도 남긴다** | 과거 틀린 콜이 계정에 남아 있는가. **삭제 흔적이 없는가** |
| **이력을 스스로 정리한다** | 콜을 스레드·핀·노션으로 모아 둔 적이 있는가 |
| **지갑이 있다** | ENS · 온체인 활동 · NFT PFP 등 |

**「틀린 것도 남긴다」가 결정적입니다.** 이런 사람은 이미 accountability 에 값을 두는 사람이고,
POI 의 첫 사용자가 될 확률이 가장 높습니다. 지우는 사람은 절대 안 씁니다.

### 찾는 경로

```
1  CryptoKOLz 디렉터리    500+ · 팔로워·분야·단가까지 공개
                          https://cryptokolz.com/twitter-crypto-kols
2  InnMind DB             250+ · 직접 접촉용 연락처 (X · YouTube · 텔레그램)
                          https://innmind.com/downloads/crypto-influencer-database-2025/
3  Kaito Mindshare Arena  생태계별 상위 계정. Yaps 는 종료됐지만 순위는 참고 가능
                          https://yaps.kaito.ai/
4  X 직접 검색            아래 쿼리로 「틀린 것도 남기는」 사람을 찾는다
```

**X 검색 쿼리 — 이게 가장 정확합니다**

```
"I was wrong about"  crypto        ← 틀린 걸 인정하는 사람
"my call on" min_faves:50          ← 콜을 명시적으로 기록하는 사람
"track record" crypto -filter:links ← 실적을 말하는 사람
"receipts" prediction crypto        ← 증거를 남기는 문화
```

디렉터리는 **에이전시가 파는 리스트**라 「돈 받고 홍보하는 사람」에 치우쳐 있습니다.
X 직접 검색이 **진짜 후보**를 찾는 데 더 낫습니다. 디렉터리는 보조로 쓰세요.

## 2. 수요측 5곳 — 프로젝트보다 에이전시가 낫습니다

### 왜 에이전시 먼저인가

| | 프로젝트 직접 | KOL 마케팅 에이전시 |
|---|---|---|
| 아는 사례 수 | 자기 캠페인 몇 건 | **수십~수백 건** |
| 통증의 선명함 | "잘 모르겠다" | **"섭외 잘못해서 얼마 날렸다"를 숫자로 말함** |
| 예산 권한 | 있음 | 대행이지만 **추천권이 큼** |
| 접촉 난이도 | 어려움 | **영업이 본업이라 미팅을 받아 줌** |

**에이전시 3 + 프로젝트 2** 구성을 권합니다. 에이전시는 여러 프로젝트의 통증을 압축해서
말해 주고, 좋게 보면 **유통 채널**이 되기도 합니다.

### 후보 유형

```
KOL 마케팅 에이전시    eakdigital · theKOLLAB · Lever Crypto · Cointraffic · LuvKaizen
                       (검색으로 확인된 실재 업체. 규모·지역이 갈리니 2~3곳 접촉)
KOL 인텔리전스 도구    Cookie3 · KOL Radar
                       → 인접 제품이라 「왜 정확도는 안 재나」를 물으면 답이 빠름
프로젝트 직접          최근 TGE·에어드랍을 한 곳. 마케팅 예산이 지금 도는 곳
                       Kaito Mindshare Arena 상위 생태계에서 고르면 됨
```

**Cookie3 · KOL Radar 는 경쟁자이자 인터뷰 대상입니다.** 왜 정확도 측정을 안 하는지
물어보면, 「기술이 없어서」인지 「수요가 없어서」인지가 나옵니다.
**후자면 POI 의 전제가 흔들립니다.** 반드시 확인하세요.

## 3. 접촉 — 채널과 순서

| 대상 | 1순위 | 2순위 |
|---|---|---|
| KOL | X DM | 텔레그램 (프로필에 공개된 경우) |
| 에이전시 | 웹사이트 문의 폼 | LinkedIn · X |
| 프로젝트 | 디스코드 팀 채널 | X DM |

**하루 5명씩, 3일간 15명.** 응답률 20~30% 가정하면 3~5건 확보됩니다.
목표 13명(8+5)을 채우려면 **최소 40명에게 보내야 합니다.**

```

1일차 오후   에이전시 5곳 · 인접 도구 2곳 · 프로젝트 5곳 목록화

3일차        응답 정리 · 인터뷰 일정 확정
4~6일차      인터뷰 실행
7일차        판정
```


**「반증가능 전망」과 「틀린것 남김」 두 칸이 비면 접촉하지 마세요.** 시간 낭비입니다.

## 6. 이 단계에서 이미 알 수 있는 것

리스트를 만드는 것만으로 답이 나오는 질문이 있습니다.

> **반증 가능한 전망을 공개적으로, 반복해서, 지우지 않고 내는 사람이
> 실제로 몇 명이나 되는가?**

30명을 훑어 **필터를 통과하는 사람이 5명 미만이면**, 그것 자체가 답입니다 —
POI 의 공급 풀이 생각보다 훨씬 얕다는 뜻이고, 인터뷰를 하기 전에 이미 신호입니다.

반대로 **12명 이상 쉽게 나오면** 공급 쪽은 해볼 만합니다.
