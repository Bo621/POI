# C8 온체인 EAS ABI 대조 (R3)

lib의 `eas-contracts v1.4.0` 인터페이스로 컴파일한 코드가, GIWA Sepolia에 실제 배포된
`1.4.1-beta.3`과 실행 시점에 어긋나지 않는지 **포크에서 왕복 호출로** 확인한다.
셀렉터만 비교하면 반환 구조체 레이아웃 변경을 놓친다 — 그래서 실제로 발행하고 되읽는다.

이 테스트는 **로컬 포크**에서만 실행된다. 공개 네트워크로 트랜잭션을 보내지 않는다.

## 파일

- 새로: `contracts/test/fork/EASForkBase.sol` — 이후 포크 테스트가 공유할 하네스
- 새로: `contracts/test/fork/EASABI.fork.t.sol`
- 수정: `contracts/foundry.toml` — 아래 "포크 프로파일"만. 다른 항목은 건드리지 말 것.
- **그 외 파일 수정 금지.** `src/` 는 절대 손대지 않는다.

## 고정 주소·값 (GIWA Sepolia, chainId 91342)

| | |
|---|---|
| EAS | `0x4200000000000000000000000000000000000021` — `version()` = `"1.4.1-beta.3"` |
| SchemaRegistry | `0x4200000000000000000000000000000000000020` |
| 고정 블록 | `31820323` (결정성·캐시 목적) |
| RPC | 환경변수 `GIWA_SEPOLIA_RPC_URL`, 기본값 `https://sepolia-rpc.giwa.io/` |

## `EASForkBase.sol` — 공유 하네스

`forge-std/Test.sol`을 상속한 `abstract contract EASForkBase is Test`.

```solidity
address internal constant EAS_ADDR = 0x4200000000000000000000000000000000000021;
address internal constant SCHEMA_REGISTRY_ADDR = 0x4200000000000000000000000000000000000020;
uint256 internal constant FORK_BLOCK = 31_820_323;

IEAS internal eas;
ISchemaRegistry internal registry;
bool internal forkAvailable;
```

`_forkSetUp()` internal 함수:

1. `string memory rpc = vm.envOr("GIWA_SEPOLIA_RPC_URL", string("https://sepolia-rpc.giwa.io/"));`
2. `try vm.createSelectFork(rpc, FORK_BLOCK) { forkAvailable = true; } catch { forkAvailable = false; return; }`
   — 네트워크가 없으면 **테스트를 실패시키지 않고 건너뛴다**(무인 실행에서 네트워크 단절이
   회귀로 보이면 안 된다). 건너뛸 때는 `vm.skip(true)`를 쓴다.
3. `eas = IEAS(EAS_ADDR); registry = ISchemaRegistry(SCHEMA_REGISTRY_ADDR);`
4. `assertEq(block.chainid, 91342);`

헬퍼 `_registerSchema(string memory schema, address resolver, bool revocable) returns (bytes32)`:
`registry.register(schema, ISchemaResolver(resolver), revocable)` 를 호출해 UID를 반환한다.

헬퍼 `_attest(bytes32 schemaUID, address attester, bool revocable, bytes32 refUID, bytes memory data) returns (bytes32)`:
`vm.prank(attester)` 후 `eas.attest(AttestationRequest({schema: schemaUID, data: AttestationRequestData({
recipient: address(0), expirationTime: 0, revocable: revocable, refUID: refUID, data: data, value: 0})}))`.

`import`는 `@ethereum-attestation-service/eas-contracts/contracts/IEAS.sol`,
`.../ISchemaRegistry.sol`, `.../resolver/ISchemaResolver.sol` 에서 가져온다.
정확한 타입 이름과 필드는 `contracts/lib/eas-contracts/contracts/` 를 직접 읽어 확인할 것.

## `EASABI.fork.t.sol` — 테스트 목록

`contract EASABIForkTest is EASForkBase`. `setUp()`에서 `_forkSetUp()` 호출.

| # | 테스트 이름 | 확인하는 것 |
|---|---|---|
| 1 | `test_Fork_EASVersion` | `IEAS(EAS_ADDR).version()` == `"1.4.1-beta.3"` |
| 2 | `test_Fork_SchemaRegistryAddress` | `eas.getSchemaRegistry()` == `SCHEMA_REGISTRY_ADDR` |
| 3 | `test_Fork_GetAttestationOnUnknownUID` | 알 수 없는 UID → revert 없이 빈 `Attestation`(uid == 0) 반환. **반환 구조체 레이아웃이 lib와 맞는다는 증거** |
| 4 | `test_Fork_RegisterSchemaRoundTrip` | 리졸버 없이(`address(0)`) 스키마 등록 → `registry.getSchema(uid)`의 `uid`·`schema` 문자열·`revocable` 일치 |
| 5 | `test_Fork_AttestAndReadBack` | 위 스키마로 `attest` → `getAttestation(uid)`의 **모든 필드**가 요청과 일치: `schema`·`attester`·`recipient==0`·`expirationTime==0`·`revocable`·`refUID`·`data`·`time != 0`·`revocationTime == 0` |
| 6 | `test_Fork_RevokeAndReadBack` | 위 attestation을 `eas.revoke`(`RevocationRequest`) → `revocationTime != 0` |
| 7 | `test_Fork_ResolverIsCalledOnAttest` | `POINoteResolver`를 새로 배포 → 그 리졸버를 붙여 `poi.note.v1` 스키마(`"bytes32 contentCommitment"`, `revocable=false`)를 등록 → `initialize(uid)` → 유효한 발행 1건이 **성공**하고, `contentCommitment=0`인 발행이 `EmptyCommitment`로 revert. **실제 EAS가 우리 리졸버를 호출한다는 증거** |
| 8 | `test_Fork_AttestSelectorsPresent` | `EAS_ADDR.code`에 `IEAS.attest.selector`·`IEAS.revoke.selector`·`IEAS.getAttestation.selector` 4바이트가 각각 존재. 바이트 검색 헬퍼를 직접 구현할 것 (`for` 루프로 4바이트 비교) |

7번이 이 항목의 핵심이다. 나머지가 다 통과해도 7번이 실패하면 배포가 성립하지 않는다.

## 포크 프로파일 — `foundry.toml`

`[profile.default]`에는 손대지 말고 **아래 두 블록만 추가**한다.

```toml
# 포크 테스트는 네트워크가 필요하므로 기본 실행에서 제외한다.
[profile.default]
no_match_path = "test/fork/*"

[profile.fork]
match_path = "test/fork/*"
```

`[profile.default]`가 이미 존재하므로 **기존 블록 안에 `no_match_path` 한 줄만 추가**하고,
`[profile.fork]` 블록은 파일 끝의 `[etherscan]` 앞에 새로 넣는다.

## 하지 말 것

- 공개 네트워크로 트랜잭션을 보내지 말 것. `--fork-url`은 로컬 실행이다. `--broadcast` 금지.
- `src/` 아래 어떤 파일도 수정하지 말 것.
- 개인키·`.env` 관련 코드를 넣지 말 것. 포크에서는 `vm.prank`로 충분하다.
- 배포 스크립트(`script/`)를 만들지 말 것 — C9의 몫이다.

## 검증

```
cd contracts
forge test                                   # 144/144, 포크 테스트는 제외됨
FOUNDRY_PROFILE=fork forge test              # 8/8
```

둘 다 통과해야 한다. 네트워크가 없으면 포크 쪽은 skip으로 표시되고 실패하지 않아야 한다.
