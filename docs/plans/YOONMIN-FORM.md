강점 · 경쟁업체**가 모두 들어 있습니다.

**2. 기타 참고 파일** — PDF 또는 동영상, 최대 2개 · 각 50MB · **선택**

**우선순위 낮음. 시간이 남으면 하세요.**

공고를 다시 확인한 결과, **제출서류는 「지원서 + 사업계획서」 둘뿐**입니다.
「기타 참고 파일」은 공고에 언급조차 되지 않고, 폼에서도 필수가 아닙니다.

| | |
|---|---|
| ✅ 확인됨 | 슬롯이 존재한다 · 동영상 가능 · 최대 2개 · 각 50MB · 선택 |
| ❌ 확인 안 됨 | 심사자가 본다 · 점수에 반영된다 · 제출이 기대된다 |

평가기준 3개 중 **「개인 또는 팀의 기술적 역량」**에만 기여할 수 있는데,
사업계획서에 **이미 실제 화면 2장과 공개 URL** 이 있습니다. 심사자가 URL 을
한 번 클릭하면 영상보다 강한 증거이고, 지갑 없이 열립니다.

```
만들게 된다면 — 2~3분, 50MB 이하로 압축
   커밋 → 구간 종료 → 정산 → 「맞음」 인장
   결과를 안 올린 결정이 「기한초과」로 바뀌는 화면
   제3자 이의가 온체인에 남는 화면
```

**단, 트랙 1 에서 지인 커밋이 실제로 들어오면 이야기가 달라집니다.**
그 커밋을 화면에서 따라가는 영상은 「남이 쓴 흔적」을 보여주는 유일한 방법이라,
그때는 만들 값이 있습니다.
