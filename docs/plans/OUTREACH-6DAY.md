# 6일 접촉 계획 — 마감 8/9

> 원래 [3일 계획](DEMAND-TARGETS.md)은 응답률 20~30%를 **2~3주** 기준으로 잡은 것입니다.
> 6일에 주말이 끼면 그 숫자가 안 나옵니다. 순서를 바꿉니다.

---

## 먼저 — 기대치를 정직하게

```
콜드 DM 40건 발송 → 6일 안에 응답        1~4건 (낙관적)
그중 인터뷰까지 성사                      0~2건
그중 즉석 커밋                            0~1건
```

**이걸로 지원서 3-4를 채우려는 계획은 실패합니다.** 콜드 DM 은 계속 보내되,
**지원서를 걸지는 마세요.** 걸 수 있는 것은 아래 트랙 1 입니다.

---

## 트랙 1 — 이미 돕겠다고 한 분들 ← **오늘, 여기가 가장 큽니다**

이전에 이렇게 말씀하셨습니다.

> 「혼자 하기엔 힘든데 공모에 당선이 되면 도움을 주시겠다는 분들이 있어서」

**그분들은 오늘 연락이 닿고, 오늘 답이 옵니다.** 낯선 사람 40명보다 이쪽이 빠릅니다.
영입 예정인 백엔드 개발자도 여기 포함됩니다.

### 무엇을 요청하나

「응원해 주세요」가 아니라 **한 가지 행동**을 요청합니다.

> 지금 5분이면 됩니다. **오늘 생각하시는 시장 전망 하나를 커밋해 보시겠어요?**
> 링크 열고, 조건 하나 적고, 구간 정하면 끝입니다.
> 결과는 나중에 자동으로 붙고, **틀려도 그대로 남습니다.**
>
> https://poi-static-production.up.railway.app

### 이걸로 무엇이 달라지나

```
지금        외부 이용자 0명
그분들 3명이 각 1건 커밋 → 커밋한 사람 3명 · 결정 3건
```

### ⚠️ 정직하게 쓰는 법 — 여기가 중요합니다

| 쓸 수 있는 것 | 쓰면 안 되는 것 |
|---|---|
| 3-4 이용자수에 **「지인 3명이 각 1건 커밋」**이라고 **관계를 밝혀** 적기 | 3-3 진행 상황을 **「일반 이용자 보유」**로 올리기 |
| 「낯선 사용자는 아직 0명」을 같은 문단에 함께 적기 | 지인 커밋을 시장 검증으로 포장하기 |

**지인 커밋은 시장 수요의 증거가 아닙니다.** 그건 「제품이 실제로 남이 쓸 수 있는
상태다」의 증거입니다. 그 이상으로 쓰면 방문평가에서 무너집니다.
그래도 0 보다는 훨씬 낫습니다 — **화면에 남의 커밋이 있는 것과 없는 것은 다릅니다.**

## 트랙 2 — 수요측 (에이전시·인접 도구) ← 오늘 발송

**에이전시는 영업이 본업이라 문의에 답합니다.** KOL 개인보다 응답이 빠릅니다.

### 대상

```
KOL 마케팅 에이전시
  Blockwiz          blockwiz.com    토론토 · 인플루언서 1,700+ · 캠페인 550+
                                    검색으로 규모가 확인된 곳
  그 외 후보         awisee.com · eakdigital · theKOLLAB · Lever Crypto
                    ⚠️ 상당수가 SEO 리스티클에서 나온 이름입니다.
                       사이트에서 실재와 규모를 직접 확인하고 보내세요.

인접 도구 (경쟁자이자 인터뷰 대상)
  Cookie3           cookie3.com     온체인 어트리뷰션
  KOL Radar                         KOL 인텔리전스
```

**Cookie3 와 KOL Radar 가 가장 값진 인터뷰입니다.** 「왜 정확도는 안 재나」를 물으면
**「기술이 없어서」인지 「수요가 없어서」인지**가 나옵니다.
**후자면 POI 의 전제가 흔들립니다.** 반드시 물어보세요. 답이 어느 쪽이든 데이터입니다.

### 발송 문구 (영어)

```
Subject: 30 min — how do you vet a KOL's actual track record?

Hi,

I'm building a tool that timestamps a market call on-chain BEFORE the outcome,
so it can't be edited or deleted afterward. It's live: 
https://poi-static-production.up.railway.app (no wallet needed)

I'm not selling anything — I'm trying to find out whether this is useless.

You've run far more campaigns than I've seen. Could I get 30 minutes to ask
how you currently decide which KOL to book, and what happens when it goes wrong?

Specifically I want to understand: when you pick a KOL, can you check whether
their past calls were actually right? If not, what do you use instead?

Thanks,
BoSung Ko / VESTAT
```

## 트랙 3 — KOL 콜드 DM ← 오늘 발송, 기대는 낮게

발송 비용이 거의 없으니 보냅니다. 다만 **지원서를 여기 걸지 마세요.**

### 찾는 법 — X 검색 쿼리

```
"I was wrong about" crypto          ← 틀린 걸 인정하는 사람
"my call on" min_faves:50           ← 콜을 명시적으로 기록하는 사람
"track record" crypto -filter:links ← 실적을 말하는 사람
"receipts" prediction crypto        ← 증거를 남기는 문화
```

### 선별 필터 — 둘이 비면 보내지 마세요

| 필수 | 확인 |
|---|---|
| **반증 가능한 전망을 낸다** | 숫자와 기한이 있는가. 「강세장 온다」류는 제외 |
| **틀린 것도 남긴다** | 과거 틀린 콜이 계정에 남아 있는가 |
| 지갑이 있다 | ENS · 온체인 활동 · NFT PFP |

**팔로워 1만~10만 중견층.** 초대형은 답하지 않고, 신진은 대표성이 없습니다.

### 발송 문구 (영어) — 짧게

```
Hi — I built a tool that timestamps a market call on-chain BEFORE the outcome,
so it can't be edited or deleted later. Live on testnet, no wallet needed:
https://poi-static-production.up.railway.app

Not selling anything. I'm trying to find out if this is useless.

Two questions, 30 min:
1. When someone new asks "has this person been right before?" — what do you show them?
2. Would you be willing to lock one call today, knowing it stays even if you're wrong?

BoSung Ko / VESTAT
```

**「팔지 않는다」와 「쓸모없는지 알고 싶다」를 명시**하는 것이 응답률을 올립니다.
방어를 내리게 하고, 솔직한 답을 받을 확률이 높아집니다.

## 8/8 판정 — 결과별로 3-4에 무엇을 쓰나

| 결과 | 3-4 이용자수에 쓸 것 | 3-3 진행 상황 |
|---|---|---|
| 지인 3명 커밋 + 낯선 응답 0 | **「지인 3명이 각 1건 커밋. 낯선 이용자는 아직 0명」** | 프로토타입 완성 |
| 낯선 KOL 1명 이상 커밋 | **「외부 이용자 N명 · 커밋 M건」** | **일반 이용자 보유** |
| 인터뷰만 성사, 커밋 0 | **「이용자 0명. N명 접촉 · M명 인터뷰 완료」** + 무엇을 들었는지 | 프로토타입 완성 |
| 아무것도 없음 | 초안대로 0 + 왜 안 모았는지 + 멈추는 기준 | 프로토타입 완성 |

**어느 칸이든 지금 초안보다 낫습니다.** 「0명」 뒤에 「N명 접촉 · M명 인터뷰」가
붙으면 같은 0 이라도 읽는 사람에게 전혀 다릅니다 — **움직이고 있다는 증거**이기 때문입니다.
