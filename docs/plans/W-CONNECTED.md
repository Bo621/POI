# 지갑 연결 상태에서 드러난 결함 — 계획

> 2026-07-29. **지갑을 연결하고 실제로 써 보고서야 나온 것들이다.**
> 미연결 상태로만 확인했기 때문에 전부 놓쳤다. E2E도 잡지 못했다 —
> 테스트는 요소의 존재를 보지 겹침을 보지 않는다.

## 측정값

```
--nav-height   4.25rem = 68px   (고정 상수)
nav 실제 높이   180px
main padding-top 124px
→ 본문 <h1> 이 nav 뒤에 가려진다 (모든 화면)
```

nav 자식별 높이:

| | 높이 | 폭 |
|---|---|---|
| brand | 27 | 96 |
| links | 27 | 206 |
| theme-toggle | 29 | 41 |
| **wallet** | **83** | **623** |
| chain | 20 | 66 |

`site-nav__wallet` 이 623px 를 차지하며 줄바꿈을 만들고, 그 안의 안내문이
높이를 83px 로 키운다.

---

## D1 — nav 가 본문 제목을 가린다 · **P0**

**증상**: 지갑 연결 후 모든 화면에서 `<h1>` 이 고정 nav 뒤로 들어간다.
`내 기록`·`기록하기`·`결정 상세` 전부.

**원인**: nav 는 `position: fixed` 인데 높이가 **내용에 따라 변한다.**
`--nav-height` 는 고정 상수이고 `main` 의 `padding-top` 이 그 값을 쓴다.
미연결 상태에서는 nav 가 68px 라 맞았고, 연결하면 180px 이 되어 어긋난다.

**고칠 것 — 구조적으로**

미디어쿼리로 상수를 하나 더 만드는 방식(현재 641px 이상에서 7.25rem)은
같은 실수를 반복한다. **nav 가 자기 높이를 스스로 알리게 한다.**

```ts
// nav 높이를 --nav-height 에 실측으로 반영한다.
// 상수로 두면 지갑 배지·안내문·경고가 늘 때마다 본문이 가려진다 — 실제로 그랬다.
const observer = new ResizeObserver(([entry]) => {
    document.documentElement.style.setProperty(
        "--nav-height", `${entry.target.getBoundingClientRect().height}px`,
    );
});
```

`nav.tsx` 에서 ref 로 붙인다. CSS 의 기본값은 그대로 두어 JS 이전에도 깨지지 않게 한다.

**검증**: 연결/미연결 양쪽에서 `main h1` 의 `top` 이 `nav` 의 `bottom` 보다 커야 한다.
E2E 에 그 단언을 넣는다 — **존재가 아니라 겹침을 본다.**

---

## D2 — 발행 경고가 전역 nav 에 상주한다 · **P1**

```
검증 지갑 스냅샷 UID를 찾지 못했습니다 (0으로 기록됩니다)
```

**문제 둘**

1. 이건 **발행 시점 경고**다. 조회만 하는 화면(`홈`·`검증하기`·`결정 상세`)에서
   계속 보일 이유가 없다. 탐색 영역에 발행 경고가 있는 것 자체가 자리가 틀렸다.
2. nav 를 623px 폭·83px 높이로 키워 D1 의 직접 원인이 된다.

**고칠 것**: nav 에서 빼고 **`기록하기`의 결정 커밋 절**로 옮긴다.
그 자리에서만 의미가 있고, 발행 직전에 읽힌다.

nav 에는 주소와 검증 배지만 남긴다.

---

## D3 — 주소가 두 번 보인다 · **P2**

`내 기록` 화면에서 nav 에 축약 주소, 본문에 전체 주소가 동시에 있다.
본문 쪽은 "누구의 기록인지" 밝히는 역할이라 남기되, **nav 와 중복되지 않게**
본문에서는 `이 지갑의 기록` 같은 맥락 문구와 함께 두거나 축약형으로 맞춘다.

판단이 필요하므로 **D1·D2 를 먼저 고치고 다시 본다.**

---

## D4 — 「검증 안 됨」이 인주색이라 오류처럼 읽힌다 · **P2**

`기록하기` 단계 표시에서 현재 단계가 `--seal`(인주색)로 강조된다.
① 저널 단계의 부가 문구 「검증 안 됨」이 같은 색을 받아 **경고로 읽힌다.**

실제로는 "저널은 검증 대상이 아니다"라는 **사실 서술**이다.

**고칠 것**: 단계 강조색은 제목에만 적용하고, 부가 문구는 `--ink-soft` 로 둔다.

---

## D5 — E2E 가 이 계층을 보지 않는다 · **P1**

27개가 전부 통과하는 동안 **모든 화면에서 제목이 가려져 있었다.**
테스트가 `getByRole('heading')` 로 존재만 확인하고 **보이는지**는 보지 않는다.

**고칠 것**: 연결 상태에서 주요 화면의 `h1` 이 nav 에 가리지 않는지 단언하는
E2E 를 추가한다. Playwright 의 `toBeInViewport` 는 겹침을 보지 않으므로
경계 상자를 직접 비교한다.

```ts
const navBox = await page.locator(".site-nav").boundingBox();
const h1Box = await page.locator("main h1").boundingBox();
expect(h1Box!.y).toBeGreaterThanOrEqual(navBox!.y + navBox!.height);
```

## 순서

```
1. D2  안내문을 nav 에서 발행 절로 이동      ← nav 를 먼저 작게 만든다
2. D1  ResizeObserver 로 nav 높이 실측
3. D5  겹침 E2E 추가 — 회귀 방지
4. D4  단계 부가 문구 색
5. D3  주소 중복 — 1·2 반영 후 다시 판단
```

## 하지 말 것

| | |
|---|---|
| `--nav-height` 상수를 키우는 것으로 때우기 | 내용이 또 늘면 같은 일이 반복된다 |
| nav 를 `position: static` 으로 | 긴 문서에서 탐색이 사라진다 |
| 안내문을 지우기 | **필요한 경고다.** 자리를 옮기는 것이지 없애는 게 아니다 |
| E2E 를 "존재 확인"으로 남겨두기 | 이번에 못 잡은 이유가 그것이다 |
