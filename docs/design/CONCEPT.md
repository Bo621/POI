# POI 프론트 컨셉 — 기와 지붕 아래의 증서

> 참고: [GASOK](https://giwa.io/gasok) (2026-07-28 실측)
> 이 문서는 **왜 그렇게 하는가**를 적는다. 정확한 값은 [TOKENS.md](TOKENS.md)에 있다.

## 1. 한 줄

**기와(GIWA)가 지붕에 얹혀 아래를 지키듯, POI는 판단을 얹어 남긴다.**

기와는 한국 전통 건축의 부재고, 증서·인장은 한국 전통 기록의 형식이다.
POI는 이미 **한지·먹·인주·인장**의 어휘로 만들어져 있다. GIWA와 억지로 맞출 필요가 없다 —
**같은 문화적 레지스터**에 이미 서 있다. 할 일은 그 사실을 눈에 보이게 만드는 것이다.

## 2. GASOK 사이트에서 실제로 측정한 것

추측이 아니라 `getComputedStyle`로 뽑은 값이다.

| | 값 | 쓰임 |
|---|---|---|
| 배경 | `#000000` | 전면 |
| 본문 | `#F5F5F0` | 따뜻한 오프화이트 — **순백이 아니다** |
| 강조 | `#FF2200` | APPLY NOW, `// 01` 라벨 |
| 보조 | `#E8B84A` | 금색 포인트 |
| 흐림 | `#9A9A94` | 따뜻하게 틴트된 회색 |
| 신호 | `#2DD488` | `● LIVE` |
| 서체 | `giwaSans` (전용) + **`Pretendard`** (한글 본문) | |

디자인 장치:
- `// 01 · THE ROADMAP` — 슬래시 접두 + 대문자 + 자간 넓은 라벨
- 머리카락 두께 구분선 (`rgba(255,255,255,0.08~0.2)`)
- 좌측 정렬, 넉넉한 세로 여백
- `● LIVE` 점 + 대문자 메타 바

## 3. 핵심 결정 — 검정으로 갈아엎지 않는다

GASOK을 그대로 흉내 내면 POI는 **GASOK 스킨**이 된다. 그건 함께한다는 표시가 아니라
정체성을 지우는 것이다. 그리고 실무적으로도 틀렸다 — **인장은 종이에 찍는 것이다.**
검정 배경에 인주 도장을 찍으면 그건 증서가 아니다.

대신 **두 모드에 각각 역할을 준다.**

| | 정체성 |
|---|---|
| **라이트 (기본)** | 한지 위의 증서 — POI 고유. 그대로 지킨다 |
| **다크** | 기와 지붕 아래 — GIWA 팔레트에 **정확히** 정렬 |

다크 모드에서 POI의 인장은 **GIWA의 빨강과 같은 색이 된다.** 그게 의지의 표현이다.
색을 비슷하게 맞춘 게 아니라 **같은 값**이다.

## 4. 이미 맞아 있던 것 두 가지

억지로 만든 정렬이 아니라는 근거다.

**인주 = GIWA 빨강.** 인주(印朱)는 주사(cinnabar) 안료다.
POI의 현재 `--seal`은 `oklch(0.55 0.185 28)`, GIWA의 `#FF2200`은 `oklch(0.637 0.249 31)`.
**색상각이 28° 대 31°** — 이미 같은 안료 계열이다. 채도와 명도만 올리면 정확히 만난다.

**GIWA 금색 = POI 한지.** GASOK의 `#E8B84A`는 `oklch(0.806 0.136 85)`,
POI의 `--paper`는 `oklch(0.977 0.008 85)`. **둘 다 색상각 85°.**
같은 따뜻한 축 위에서 채도만 다르다. 그래서 금색을 POI에 넣어도 이물감이 없다.

> 이 두 값은 계산해서 얻었다. 구현 전에 `oklch.com` 등으로 한 번 대조할 것.

## 5. 가져오는 것 / 가져오지 않는 것

### 가져온다

1. **Pretendard** — GIWA의 한글 본문 서체. 지금의 IBM Plex Sans KR보다 한글 조판이 낫고,
   무엇보다 **같은 서체를 쓴다는 사실 자체가 정렬이다.** OFL 라이선스라 문제없다.
2. **`//` 섹션 라벨** — GASOK에서 가장 알아보기 쉬운 장치이고, POI의 공문서 톤과도 맞는다.
   문서의 조항 번호처럼 읽힌다. `// 02 · 결과 등록`
3. **따뜻한 중성색** — `#F5F5F0` / `#9A9A94`. POI는 이미 이 원칙을 지키고 있다(순백·순흑 없음).
   다크 모드 값만 GIWA 쪽으로 옮긴다.
4. **금색 강조** — 지금 POI에 없는 색. **검증된 것**을 표시하는 데 쓴다.
5. **기와 문양 구분선** — GIWA 로고 마크는 겹친 기와 물결(`≋`)이다.
   절 구분선에 이 리듬을 아주 옅게 넣는다. 장식이 아니라 서명이다.

### 가져오지 않는다

| | 이유 |
|---|---|
| 거대 2단 디스플레이 헤드라인 | POI는 증서다. 광고 헤드라인 톤이 들어오면 기록의 무게가 사라진다 |
| 터미널·해커 모티프 (`>` 프롬프트, 커서 깜빡임) | GASOK은 빌더에게 말하고, POI는 **검증하는 제3자**에게 말한다 |
| 검정 배경을 기본으로 | 위 §3 |
| `● LIVE` 같은 실시간 연출 | POI에 실시간인 것이 없다. 없는 것을 있는 척하지 않는다 |
| giwaSans | 전용 서체다. 남의 브랜드 서체를 제품에 쓰지 않는다 |

## 6. 넘지 않는 선

**구조와 문구는 건드리지 않는다.** 지금 E2E 26개가 화면 문구로 요소를 찾는다.
색·서체·간격만 바꾸면 전부 그대로 통과하고, `<h2>`를 옮기거나 문구를 바꾸면 깨진다.

그리고 §6.3 배지 정책은 디자인에도 적용된다.

- 개수·비율·적중률을 숫자로 강조하지 않는다
- 정렬·랭킹·"상위 n%"를 만들지 않는다
- 색으로 우열을 표현하지 않는다 — 인장 색은 **상태**지 등급이 아니다

## 7. 이 컨셉이 성공했는지 판정하는 법

심사자가 POI 화면을 보고 **"GIWA 생태계의 제품이구나"** 라고 느끼되,
**"GASOK 페이지를 베꼈네"** 라고는 생각하지 않으면 성공이다.

구체적으로:
- 다크 모드 인장 색을 스포이드로 찍으면 `#FF2200`이 나온다
- 본문 서체가 GIWA와 같다
- 그런데 레이아웃·톤·어휘는 증서지 랜딩 페이지가 아니다
