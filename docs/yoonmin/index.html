// 10 차별점

사전에 고정하고, 플랫폼에 기대지 않는다

① 사후 관찰 → 사전 고정

관찰형은 「이 사람이 그때 뭐라고 했나」를 나중에 주워 담는다. 지운 글은 없는 글이 되고, 기준은 관찰자가 정한다.

POI 는 본인이 결과를 알기 전에 스스로 고정한다. 무엇을 볼지도 그때 선언하고, 나중에 바꿀 수 없다.

② 플랫폼 비의존

Kaito 는 2026년 1월 X 가 API 접근을 차단하면서 주력 제품 Yaps 를 종료했다. 남의 플랫폼 위에 세운 측정은 그 플랫폼이 문을 닫으면 같이 닫힌다.

POI 에는 끊길 API 가 없다. 사용자가 스스로 온체인에 커밋하고, 판정은 컨트랙트가 한다.

정직하게 — 기술 장벽은 낮다

같은 것을 만드는 데 특별한 기술이 필요하지 않다. 차별은 기술이 아니라 무엇을 금지했는가에 있다.

성과 랭킹✗ 의도적 배제
수익률 공개✗
배지 개수 정렬✗

완전성을 보장하지 못하는데 순위를 세우면 순위 자체가 거짓말이 된다. 랭킹을 넣는 순간 목적이 무너지므로, 넣을 수 있어도 넣지 않는다.

해자는 시간이 만든다

기록은 쌓인 뒤에 대체 불가해진다. 「3년치 사전 커밋 이력」은 나중에 만들 수 없다. 초기에는 해자가 없다 — 그래서 공급 확보가 첫 6개월의 유일한 목표다.

// 12 실제 화면 ①

결과를 안 올린 판단은 「기한초과」로 남는다. 발행자가 지우거나 감출 수 없다.

// 13 실제 화면 ②

같은 주소면 제3자 이의로 읽히지 않는다. 이의자가 검증 지갑인지도 함께 붙는다 — 화면의 「미검증 지갑」이 그것이다.

관측값과 출처를 같이 남긴다

90,688,000 · upbit-1m-candles(재계산) — 이의도 근거를 대야 한다. 제3자가 같은 절차로 다시 확인할 수 있다.

건수를 세지 않는다

지갑 생성 비용이 사실상 0 이라 개수는 언제든 부풀릴 수 있다. 목록만 보여주고 숫자를 만들지 않는다.

「조회된 것이 전부라는 보장은 없습니다」를 목록마다 표시한다. 보장 못 하는 것을 숨기지 않는다.

가장 큰 반론이 좁혀진다 — 「좋은 판단만 골라 기록하면?」

거래가 있었는데 결정이 없으면 그것도 드러나기 때문이다. 완전성을 완전히 풀지는 못해도, 지금보다 훨씬 좁아진다.

왜 아직 못 하나 — 직접 확인한 사실

국내 거래소는 약관이 서브파티 접근을 금지한다. 요청해서 되는 문제가 아니라 제도가 바뀌어야 하는 문제다. 직전 제품을 만들며 직접 부딪혀 확인했다.

그래서 해외 거래소부터 연다. 해외는 읽기 전용 연동이 가능하고, POI 의 타겟도 글로벌이다. 국내는 열리면 붙인다.

①②는 남의 허락 없이 오늘 돌고 있다. ③이 안 열려도 제품은 「말한 것」까지 증명하는 형태로 남는다 — 로드맵 전체가 남의 손에 걸려 있지 않다.

POI 는 「발행자가 낸 값과 결과가 어긋나지 못하게 하고, 기준을 나중에 못 바꾸게 한다」는 제품이다. 이 두 문장이 커리어와 겹친다.

1인이 어떻게 여기까지 만들었나 — 기획을 문서로 먼저 확정하고, 구현과 리뷰를 분리하고, 테스트를 게이트로 뒀다. 그 체계가 실제로 잡아낸 것들이 있다 — 화면의 조건 기호 6개가 전부 틀리게 표시되던 것, 심사자가 실행하면 실패했을 검증 명령, 길이를 유지한 payload 변조. 앞의 둘은 단위 테스트가 통과하는 동안 살아 있었다.

// 25 확장

POI 가 하는 일은 「결과가 나오기 전에 고정하고, 나중에 제3자가 확인한다」 이다. 컨트랙트는 고정된 내용이 무엇인지 보지 않는다 — 해시와 구간, 산술만 검사한다. 그래서 고정할 내용만 바꾸면 다른 것도 같은 방식으로 증명된다.
