## 제출 직전에 다시 판단할 것 — 두 문항

인터뷰 결과에 따라 답이 바뀝니다. [접촉 계획](../docs/plans/OUTREACH-6DAY.md)

**3-3 진행 상황**

```
지금            프로토타입 완성
낯선 사용자가 커밋하면  → 일반 이용자 보유 로 올린다
지인 커밋만 있으면      → 올리지 않는다
```

**3-4 이용자수** — 8/9 시점의 접촉·인터뷰 숫자를 넣습니다.
같은 0 이라도 뒤에 「N명 접촉 · M명 인터뷰 완료」가 붙으면 전혀 다르게 읽힙니다.

> **지인 커밋은 관계를 밝혀서만 씁니다.** 시장 수요의 증거가 아니라
> 「제품이 남이 쓸 수 있는 상태다」의 증거입니다. 그 이상으로 포장하면
> 방문평가에서 무너집니다.
