## 1. 9쪽 — 가상 인물 「A」를 없앤다

**왜** 25장 중 사람이 나오는 유일한 장인데 그 사람이 존재하지 않는다.
심사자가 「아직 아무도 없구나」를 처음 체감하는 자리가 하필 감정이입이 시작될 자리다.

**주의** 마루 피드의 실제 발행자는 **우리 지갑**이다. 「실제 사용자」로 바꿀 수 없다.
그래서 **인물을 실존 인물로 교체하는 것이 아니라, 인물 자체를 없앤다.**
가상 인물을 세우지 않고 **타겟 집단이 지금 실제로 하는 행동**으로 서술한다.
집단 행동 서술은 허구가 아니라 관찰이고, 4쪽 FINRA 수치와 10쪽 경쟁 분석이 뒷받침한다.

### 바꿀 것

`<p class="lede">` 안의 다음 문장을 지운다.

```
유료 뉴스레터를 운영하는 <strong>A</strong>. 구독자는 “이 사람 말이 맞았나”를 묻고, A 는 증명할 방법이 없습니다.
```

대신 이렇게 쓴다.

```
크립토 KOL 은 콜을 냅니다. 구독자와 팔로워는 <strong>“이 사람 말이 맞았나”</strong>를 묻고,
지금은 <strong>답할 방법이 없습니다.</strong>
```

`.ba` 블록의 「지금」 칸 세 문단에서 **A 를 주어로 쓰는 표현을 집단 서술로** 바꾼다.
내용은 유지하고 주어만 바꾼다.

```
3월에 “반도체 조정 온다”고 썼다. 맞았습니다. → 콜이 맞았습니다.
그런데 구독자에게 보여줄 게 지난 메일 캡처뿐입니다. → 그런데 보여줄 게 지난 글 캡처뿐입니다.
```

`.src` 각주의 다음 문장은 **인물이 사라졌으므로 통째로 지운다.**

```
A 는 특정 인물이 아니라 <b>타겟을 설명하기 위한 인물상</b>이다. 실제 사용자 확보는 3개월 게이트에서 검증한다.<br>
```

각주의 나머지(자본시장연구원 인용)는 그대로 둔다.

## 2. 2쪽 요약에 「두 층」을 한 줄 넣는다

**왜** 가장 강한 카드(소비자 앱)가 14쪽에 나온다. 그전까지 「프로토콜만 있고 쓸 이유가
없다」는 의심이 쌓인다. 요약에서 미리 막는다.

`.src` 문단 맨 앞에 한 문장을 넣는다. 기존 문장은 그대로 뒤에 둔다.

```
<b>증명 레이어와 그 위의 소비자 피드가 각각 배포돼 함께 돌고 있습니다.</b>
```

## 3. 타겟 용어를 「크립토 KOL」로 통일한다

**왜** 6쪽은 영어권 크립토 KOL 로 좁혔는데 5쪽·9쪽이 뉴스레터로 돌아간다.
심사자가 「누구를 위한 겁니까」를 물으면 답이 하나로 안 나온다.

**5쪽은 손대지 않는다.** Substack·TipRanks 는 *카테고리가 사업이 된다*는 근거이지
타겟 서술이 아니다. 오해를 막기 위해 해당 표의 맨 아래 문장에만 한 마디를 덧붙인다.

```
빈칸은 하나입니다 — <strong>사전에 고정된 판단.</strong>
  → 뒤에 이어 붙인다:  우리는 그 빈칸을 <b>크립토 KOL</b> 에서 먼저 채웁니다.
```

**9쪽**은 1번 작업에서 이미 「크립토 KOL」로 바뀐다. 추가 작업 없음.
