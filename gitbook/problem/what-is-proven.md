# 무엇이 증명되고 무엇이 안 되나

## 증명하는 것

| 명제 | 근거 | 강도 |
|---|---|---|
| 발행자가 t0에 어떤 내용을 확정했고 이후 바꿀 수 없다 | commitment | 강 |
| 공개 후 공개된 내용이 t0에 확정된 것과 동일하다 | commitment 재계산 | 강 — 공개한 경우에만 |
| 커밋된 결정이 이후 변조되지 않았다 | commitment + DAG 무결성 | 강 |
| 결정이 발행 지갑에 귀속된다 | 서명 | 강 |
| 정산 결과가 관측값과 산술적으로 일치한다 | 컨트랙트 강제 | 강 |
| 관측 구간이 결정 시점 이후로만 설정됐다 | 컨트랙트 강제 | 강 |
| 선언 조건의 정산 결과가 재현 가능하다 | 출처·버전·로직 버전 기록 | 중 |
| 정산 결과에 이의가 제기됐다 | Challenge attestation | 중 |

commitment는 발행자가 t0에 내용을 확정했고 바꿀 수 없음을 증명합니다. 그 내용이
무엇인지는 공개(Reveal) 전까지 제3자가 알 수 없습니다.

## 증명하지 않는 것

| 명제 | 성격 |
|---|---|
| 이 이유가 진짜 이유였다 | 원리적 불가 — 내심의 상태는 관측 불가 |
| 이 근거가 결정을 유발했다 | 원리적 불가 — 자료의 존재 ≠ 인과 |
| 이 판단이 좋은 판단이다 | 설계상 배제 |
| 정산 데이터 출처가 진실이다 | 현 단계 미지원 — Phase 2 오라클 |
| 모든 결정이 기록됐다 | 현 단계 미지원 |
| 모든 실행이 결정과 대응한다 | 현 단계 미지원 |

기록의 **무결성**은 증명하지만 기록의 **완전성**은 증명하지 못합니다.
