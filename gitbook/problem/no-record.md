# 판단은 남지 않는다

```
남는 것     :  2026-05-14  BTC 매도  0.4개
남지 않는 것 :  왜 팔았는가
              무엇을 보고 그렇게 판단했는가
              그 판단이 언제 만들어졌는가
              선언한 조건이 실제로 일어났는가
```

## 사후 서사 재구성

```
결과 확인  →  그 결과를 설명하는 판단을 사후 작성  →  "내 판단대로 됐다"
```

거짓말 탐지로 잡히지 않습니다. 진술 내용이 사실이기 때문입니다. 다만 **그 진술이
만들어진 시점**이 기록되지 않았을 뿐입니다.

GitHub의 가치는 저장이 아니라 `git blame`입니다. 커밋은 변경분이 아니라
**"왜 바꿨는가"**의 기록입니다.
