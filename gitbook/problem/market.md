# 시장과 규제

> 이 문서의 수치는 전부 공개 출처에서 가져왔습니다. 문서 끝에 출처를 모아 두었습니다.
> 모르는 말이 나오면 [용어집](../appendix/glossary.md)을 보세요.

## 신뢰가 옮겨갔다

제도권 리서치를 떠난 투자자가 유튜버와 뉴스레터로 옮겨갔습니다.
증권사 리서치가 매도 의견을 내기 어렵다는 것을 투자자들이 알기 때문입니다.

문제는 **옮겨간 곳에 검증 수단이 없다**는 것입니다.

자본시장연구원은 투자의견이 "주관적인 기준에 따라 정의된 단순한 체계로 제공되는
정성적 정보이기 때문에 **사후적인 검증이나 비교가 매우 어렵다**"고 지적합니다.

핵심은 데이터 부족이 아닙니다. **판단이 결과 이후에 수정 가능하다는 구조**입니다.
지우면 그만이고, 지운 사람과 안 지운 사람이 화면에서 구별되지 않습니다.

## 규제는 이미 들어왔다 — 전부 사후 단속이다

| 시점 | 무엇 |
|---|---|
| 2024.08.14 | 자본시장법 개정 시행. **양방향 유료 리딩방은 등록 투자자문업자만** 운영할 수 있게 됐습니다 |
| 2025.10.29 | 금융감독원, 해외주식 리딩방에 **소비자경보 「주의」** 발령 |

규제 자체가 **문제가 실재한다는 증거**입니다. 그런데 방식이 전부 사후입니다 —
피해가 생긴 뒤 신고하고, 신고가 접수되면 조사합니다.

그 사후 절차가 얼마나 작동하는지가 다음 숫자입니다.

| | |
|---|---|
| 6,300건 | 유사투자자문업자 관련 민원 (2017.03 ~ 2025.08, 금융감독원) |
| 975건 (16%) | **미등록 투자자문** — 분모는 분류 가능분 6,101건 |
| 3,068건 (50.3%) | 유료 서비스 환불·계약 해지 요구 — 같은 분모 |
| 104건 (1.7%) | **포상금이 지급된** 신고. 총 7,610만원 |

포상금이 지급된 신고는 100건 중 두 건이 안 됩니다. 이 숫자가 적발률은 아니지만,
신고에 기대는 방식이 잘 작동하지 않는다는 신호입니다. 사후 단속이 어려운 이유는
입증할 원본 기록이 남아 있지 않기 때문입니다.

## 모수

| | |
|---|---|
| 가상자산 투자자 | 1,022만 명 · 보유 69.9조 원 (2026.02, 5대 거래소가 국회에 제출한 자료) |
| 증감 | 2022년 587만 명 → 2025.08 1,099만 명 (**+87.2%**) 이후 조정 |

모수가 크다는 것이 곧 시장이라는 뜻은 아닙니다. **위 규제 수치와 함께 읽어야
"문제를 겪는 사람이 실재한다"가 됩니다.**

## 이미 나와 있는 대안 — 그리고 무엇이 다른가

이 문제를 다루는 서비스가 이미 있습니다. 국내에는 인간지표, 해외에는 TipRanks 가 있습니다.

### 인간지표 (국내)

경제 유튜버의 발언을 모아 시장 지수와 대조해 적중률을 매기는 서비스입니다.
공개된 수치로 **19명 · 668건**을 검증했고, 기준은 「발언일 +1거래일 종가」입니다.
서비스 스스로 결과가 「가상·재미」라고 밝히고 있습니다.

### TipRanks (해외)

2009년부터 애널리스트·블로거·헤지펀드의 공개 추천을 추적합니다.
데이터베이스는 96,000명 이상이고, 통계적 유의성을 위해 1인당 최소 10~15건을 요구합니다.

### 갈라지는 지점 — 관찰이냐, 사전 고정이냐

둘 다 **제3자가 밖에서 관찰**하는 방식입니다. 그래서 세 가지가 따라옵니다.

| | 관찰형 (인간지표 · TipRanks) | POI |
|---|---|---|
| 누가 대상이 되나 | **관찰자가 고른 사람만** — 19명, 또는 추적 가능한 매체 | **누구나** 스스로 등록 |
| 무엇을 기준으로 판정하나 | **관찰자가 정한다** — 예: 발언일 +1거래일 종가 | **본인이 사전에 선언한다** — 지표·조건·관측 구간 |
| 대상자가 동의했나 | 아니다. 본인이 통제할 수 없다 | 본인이 커밋한다 |
| 판정 주체 | 서비스 운영자 | **컨트랙트** (I17 산술 강제) |
| 판정 근거를 제3자가 재현하나 | 서비스가 공개하는 만큼 | 온체인 값 + 공개 1분봉으로 **직접 재계산** |

관찰형이 나쁜 것이 아닙니다. **다른 문제를 풉니다** — 이미 공개적으로 말한 사람을
사후에 채점하는 문제입니다. 그래서 대상이 제한되고, 기준을 본인이 동의한 적이 없고,
서비스가 문을 닫으면 기록도 사라집니다.

POI 가 푸는 것은 **"내가 그때 이렇게 판단했다"를 본인이 증명하는 문제**입니다.
기준을 본인이 결과 이전에 고정하고, 판정을 컨트랙트가 하고, 기록이 체인에 남습니다.

> **관찰형이 19명·668건에 머무는 이유**가 이 구조 차이입니다.
> 밖에서 관찰하려면 관찰자가 사람을 고르고 발언을 수집하고 기준을 정해야 합니다.
> 사전 고정 방식은 **본인이 커밋하는 만큼** 늘어납니다.

## 그래서 무엇이 검증돼야 하는가

이 시장 분석이 맞다면 **사람들이 판단을 반복해서 남길 것**입니다.
그것이 [로드맵](../limits/roadmap.md)의 첫 검증 대상이고, 아직 검증되지 않았습니다.

지금 온체인에 있는 것은 화면 확인용으로 미리 발행해 둔 실제 기록(`fixture`)뿐이고,
실사용자는 없습니다 ([배포 상태표](../limits/status.md)).
