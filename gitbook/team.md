## 왜 이 사람이 이 문제를 푸는가

POI 는 **「발행자가 낸 관측값과 정산 결과가 어긋나지 못하게 하고, 기준을 나중에 못 바꾸게 한다」**
는 제품입니다. 이 두 문장이 제 커리어와 겹칩니다.

| 해온 일 | POI 에서 대응하는 것 |
|---|---|
| 펀드 기준가 · 지수 산출 로직 설계 (KG제로인 · 알케미랩) | 지표 정의를 문서로 고정하고 그 [바이트 해시를 온체인에](design/metrics.md) 박는다 |
| 운용 성과 정산 · 손익 검수 시스템 0→1 (비씨랩스) | 정산 산술을 [컨트랙트가 재계산해 대조](design/invariants.md)한다 (`I17`) |
| 낙찰 대금 분배 · 원장 대사 설계 (빗썸라이브) | 온체인 확정 트랜잭션을 원천으로 삼는 구조 |
| 거래소 이상거래 탐지 0→1 (피어테크) | 선점·다중지갑·복사 공격을 [설계 단계에서 차단](design/security.md) |
| Upbit 운영 지원 (코네) | GIWA · 도장 생태계의 운영 맥락 |

**정산과 원장 정합성을 제품으로 만들어 온 사람이 그것을 프로토콜로 옮긴 것이 POI 입니다.**

## 1인이 어떻게 여기까지 만들었나

AI 개발 체계를 제품처럼 운영합니다.

```
기획   PRD · 화면설계서 · 수용기준을 먼저 문서로 확정
구현   Claude Code
리뷰   Codex 로 교차 검증 — 구현자와 리뷰어를 분리한다
검증   테스트를 게이트로 두고, 통과하지 못하면 병합하지 않는다
```

이 체계가 POI 개발 중 실제로 잡아낸 것들입니다.

- 화면의 조건 기호 6개가 전부 잘못 표시되던 것 (`op=1` 은 `≥` 인데 `≠`)
- 지표 해시 대조 명령이 틀려 심사자가 실행하면 실패했을 것
- 지갑을 둘 이상 설치하면 `window.ethereum` 을 한쪽이 가로채 세션 복원이 깨지던 것
- 결정 payload 가 길이만 검사해 **길이를 유지한 offset 변조**가 통과하던 것

**앞의 셋은 단위 테스트가 통과하는 동안 살아 있었습니다.** 테스트가 아니라 실행과 교차
리뷰가 잡았고, 그 과정을 저장소에 기록으로 남겼습니다. 마지막 하나는 교차 리뷰가 잡아
**컨트랙트를 재배포**했습니다 — 주소와 스키마 UID 가 전부 바뀌는 비용을 치렀습니다.

## 1인 팀의 한계 — 숨기지 않습니다

| | |
|---|---|
| 권한 분산 | `POIDecisionResolver` 의 owner 는 2-of-2 Safe 지만 **두 키를 같은 사람이 보유**합니다. 단일 키 탈취 위험은 줄었으나 권한이 여러 주체로 나뉜 것은 아닙니다 ([보안 모델](design/security.md)) |
| 보안 감사 | **외부 감사를 받지 않았습니다.** 내부 테스트와 교차 리뷰뿐입니다 |
| 법률 검토 | 정산·이의 공개 범위에 대한 법률 검토가 열려 있습니다 ([하지 못한 것](limits/not-yet.md)) |
| 대역폭 | 컨트랙트·프론트·검증기·문서를 한 사람이 씁니다. 동시에 여러 갈래를 밀 수 없습니다 |

## 선발되면 가장 먼저 하는 것 — 백엔드 1인 영입

**영입 후보가 이미 정해져 있습니다.** 선발 시 지원금으로 합류시킬 계획입니다.

| | |
|---|---|
| 경력 | 백엔드 개발 10년차 |
| 관련 경험 | **스마트 컨트랙트 기반 경매 시스템 구축** · P2E 게임 개발 프로젝트 참여 |
| 맡을 것 | 오프체인 검증기 운영화, 외부 조회 API([3단계](limits/roadmap.md)), 인덱싱·데이터 파이프라인 |

**왜 이 사람인가** — POI 의 다음 병목은 컨트랙트가 아니라 **오프체인**입니다.
검증기를 상시 서비스로 만들고, 조회 API 를 열고, RPC 조회 한계를 인덱서로 넘어서는 일입니다.
스마트 컨트랙트로 경매 정산을 만들어 본 사람은 **온체인 확정과 오프체인 원장을 맞추는
작업**을 이미 해 봤습니다. POI 가 하는 일과 같은 종류입니다.

> **아직 합류하지 않았습니다.** 현재 팀 역량으로 세지 않습니다.
> 여기 적는 이유는 「선발되면 무엇에 쓰겠는가」가 심사의 질문이기 때문입니다.
> 계획이 구체적이라는 것은 밝히되, 없는 인력을 있다고 말하지는 않습니다.
