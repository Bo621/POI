# 비용

> **2026-07-29 22:24 KST 실측입니다.** gas 사용량은 GIWA Sepolia에 실제로 발행한
> 트랜잭션의 영수증(`eth_getTransactionReceipt`)에서 읽었고, ETH 시세는
> 업비트 `KRW-ETH` 공개 시세입니다. **추정한 값이 없습니다** —
> 다만 네 건 중 세 건만 아래에 tx 를 인용했습니다.
>
> 근거와 재계산 방법: [COST.md](https://github.com/Bo621/POI/blob/main/docs/submission/COST.md)

```
L2 가스 가격     0.001000 gwei      (실측)
ETH/KRW          2,731,000원        (업비트, 2026-07-29 22:24 KST)

결정 커밋        424,275 gas  →  1.21원    tx 0x53dda9b6…6225
이의 발행        445,102 gas  →  1.25원    tx 0xca360442…791c
정산 발행        594,945 gas  →  1.67원    tx 0x630ee3e2…  (배포 지갑)
기한초과 결정    444,187 gas  →  1.27원    tx 미인용
```

앞의 세 건은 위 tx 영수증(`eth_getTransactionReceipt`)에서 직접 읽을 수 있습니다.
**「기한초과 결정」만 이 문서에 tx 를 인용하지 못했습니다** — 같은 방식으로 측정했지만
영수증을 특정해 두지 않았습니다. 검증하실 값은 앞의 세 건입니다.

비용의 **96%가 L2 실행 가스**이고 L1 데이터 수수료는 4%입니다.
L2라서 싼 것이 아니라 **가스 가격이 0.001 gwei로 낮기 때문**입니다.

비용이 커밋 빈도를 정하고, 커밋 빈도가 t0의 해상도를 정합니다.

## 이더리움 L1 비교

같은 컨트랙트이므로 **gas 사용량은 같습니다.** 차이는 가스 가격뿐입니다.

| | 가스 가격 | 결정 커밋 1건 |
|---|---|---|
| GIWA Sepolia | 0.001000 gwei | **1.21원** |
| 이더리움 메인넷 | 0.734 gwei | **850원** |
| | | **약 702배** |

L1 가스 가격은 `eth_gasPrice` @ `ethereum-rpc.publicnode.com` 실측입니다.

> **이 배수는 측정 시점의 값입니다.** L1 가스 가격은 혼잡도에 따라 수십 배 움직입니다.
> 0.734 gwei는 낮은 편이므로 혼잡할 때 배수는 더 커집니다.
> **L1에서 실제로 발행해 보지는 않았습니다** — 실측 gas × 실측 L1 가스 가격입니다.
