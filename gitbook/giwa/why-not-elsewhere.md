# 고비용 체인에서 무너지는 지점

저비용은 "있으면 좋은 것"이 아닙니다. 비용이 커밋 빈도를 정하고, 커밋 빈도가
POI가 증명할 수 있는 시점의 해상도를 정합니다.

## 갈래 1 — 여러 결정을 한 트랜잭션에 묶는다

절감되는 것은 기본가스 21,000뿐입니다. EAS는 한 배치의 모든 attestation에 같은
블록 timestamp를 넣지만, I2는 부모가 자식보다 엄격히 빨라야 한다고 강제합니다.
부모 링크를 생략하면 한 달치 판단의 선후 관계가 사라집니다.

## 갈래 2 — 집계 commitment 하나로 묶는다

비용은 줄지만 개별 결정에 온체인 UID가 없어집니다. 정산과 미발행 상태는
decision UID를, Challenge는 settlement UID를 참조하므로 붙을 대상이 사라집니다.

| | GIWA 결정 단위 | 고비용·트랜잭션 묶기 | 고비용·집계 commitment |
|---|---|---|---|
| 결정 건당 비용 | **1.21원**(실측) | 약 705원(묶기 17% 절감 후) | 낮음 |
| 개별 결정 UID | 있음 | 있음 | 없음 |
| 정산 · 미발행 · Challenge | 작동 | 작동 | 참조 대상 없음 |
| 결정 간 선후 관계 (I2) | 보존 | 끊김 | 없음 |
| t0 해상도 | 분 | 배치 주기 | 배치 주기 |

다른 체인에서도 비용을 그대로 지불하면 기능은 유지됩니다. GIWA에서는 차별화가
강화되고, 고비용 체인에서는 경제성과 시점 해상도가 나빠집니다.

---

## 그러면 다른 저비용 L2 는 왜 아닌가

**저비용만이 이유라면 다른 L2 도 됩니다.** Base·Optimism·Arbitrum 도 결정 단위 커밋을
감당할 만큼 쌉니다. 여기서 정직하게 갈라야 합니다.

**EAS 프리디플로이는 GIWA 만의 것이 아닙니다.** EAS 와 SchemaRegistry 는 OP Stack 의
표준 프리디플로이라 Optimism·Base 에도 **같은 주소**(`0x4200…0021`, `0x4200…0020`)에
있습니다. POI 를 다른 OP Stack 체인에 올리는 데 기술적 장벽은 없습니다.

그래서 「GIWA 여야 하는 이유」는 비용도 EAS 도 아닙니다.

| | 다른 저비용 L2 | GIWA |
|---|---|---|
| 결정 단위 커밋 경제성 | 가능 | 가능 |
| EAS 프리디플로이 | **있음** (OP Stack 표준) | 있음 |
| **「누가 말했는가」의 온체인 근거** | 없음 — 직접 만들거나 외부 신원 서비스를 붙여야 한다 | **도장 Verified Address** ([연동 완료](../intro/deployed.md)) |
| 「그때 무엇을 들고 있었나」 | 없음 | 도장 Verified Balance (미사용, [2단계](../limits/roadmap.md)) |
| 관측값의 독립 증명 | 범용 오라클 — 국내 거래소 가격은 직접 조달 | Upbit Oracle (예정) |
| 판단을 남길 사람이 이미 있는 곳인가 | 일반 L2 사용자 | **업비트 사용자 기반** |
| 값을 숨긴 조건 증명 | 직접 구축 | 보자기 (예정, 문서 미공개) |

**핵심은 신원과 사용자입니다.** POI 의 등급 두 축 중 하나가 「누가 말했는가」인데
([등급 읽는 법](../appendix/glossary.md)), 그 축을 온체인으로 채워 주는 것이 도장입니다.
다른 체인에서는 이 축이 `SELF_DECLARED` 에서 올라가지 못하거나, 우리가 신원 체계를
직접 만들어 「우리를 믿어라」로 돌아가야 합니다. **이 제품이 하지 않으려는 바로 그것입니다.**

그리고 판단을 남길 사람이 없는 곳에 기록 도구를 두는 것은 의미가 없습니다.
[시장](../problem/market.md)에서 본 문제 — 검증 수단 없이 신뢰가 개인에게 옮겨간 것 —
은 국내 투자자의 문제이고, 그 사람들이 이미 있는 곳이 업비트·GIWA 입니다.

> **옮기면 무엇을 잃는가** — 컨트랙트와 불변식은 그대로 돕니다.
> 잃는 것은 도장 연동(등급의 한 축), 예정된 Upbit Oracle·보자기, 그리고 사용자 접점입니다.
> **기술이 아니라 생태계를 잃습니다.**
