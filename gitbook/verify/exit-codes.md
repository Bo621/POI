# 종료코드의 의미

| 종료코드 | 뜻 |
|---|---|
| 0 | `MATCH` — 온체인 정산 또는 공개 내용이 재계산과 일치 |
| 1 | `MISMATCH` — 일치하지 않음 |
| 2 | 조회·입력 실패 |
| 3 | 검증할 대상 없음 (예상 결과 미선언 · 미정산 · 관측 불가) |

`3`을 `0`으로 두면 "검증됨"과 구별되지 않고, `1`로 묶으면 "틀림"과
뭉개집니다. **검증하지 못한 것과 틀린 것은 다릅니다.**

## 판정 흐름

```mermaid
flowchart TB
    S["poi-verify <decisionUID>"] --> A{"조회 성공?"}
    A -->|"아니오"| E2["2 — 조회 실패"]
    A -->|"예"| N{"예상 결과를<br/>선언했는가?"}
    N -->|"아니오"| E3n["3 — 검증할 대상 없음<br/>(NOT_REQUIRED)"]
    N -->|"예"| B{"정산이 있는가?"}
    B -->|"아니오"| E3a["3 — 검증할 대상 없음"]
    B -->|"예"| C{"관측값을 재계산할 수 있는가?"}
    C -->|"아니오"| E3b["3 — 관측 불가"]
    C -->|"예"| D{"온체인 값과 일치?"}
    D -->|"예"| E0["0 — MATCH"]
    D -->|"아니오"| E1["1 — MISMATCH"]
```

종료코드 `3`은 오류가 아니라 **아직 판정할 수 없다**는 상태를 따로 알리는 값입니다.
