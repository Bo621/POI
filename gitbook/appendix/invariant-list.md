# 불변식 전체 목록

`contracts/src/*.sol`의 번호 주석을 기준으로 전수 정리한 목록입니다.

| 번호 | 컨트랙트가 거부하는 것 |
|---|---|
| I1 | 빈 결정·트리거 commitment |
| I2 | 부모의 시각이 자식보다 빠르지 않은 결정 |
| I3 | 다른 attester의 부모 결정 |
| I4 | 커밋 시점보다 과거인 관측 구간 |
| I5 | 허용되지 않은 지표 |
| I6a | 시작 시각이 허용 범위보다 먼 구간 |
| I6b | 허용 길이보다 긴 관측 구간 |
| I6c | 허용 범위 밖의 유예기간 |
| I7 | 관측 구간 종료 전 정산 |
| I8 | 구간 종료 시각과 다른 관측 시각 |
| I9 | 기존 활성 정산이 있는데 새 정산 발행 |
| I10 | 결정 소유자가 아닌 attester의 정산 |
| I11 | 철회 불가능한 정산 |
| I12 | EAS `refUID`와 POI 참조의 불일치 |
| I13 | 마지막 정산을 잇지 않는 정정 |
| I14 | 최대 개수를 넘는 부모 |
| I15 | 동일인의 중복 활성 이의 |
| I16 | 관측값이 없는데 `INDETERMINATE`가 아닌 결과 |
| I17 | 관측값과 산술적으로 모순되는 결과 |

코드에는 `I3b`(다른 attester의 노트 승격)와 `I6d`(예상 결과가 없을 때 결과 필드가
0이 아님)도 관련 번호의 세부 불변식으로 표시됩니다.
