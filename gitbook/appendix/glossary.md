# 용어집

이 백서에 나오는 말들을 한 줄로 풀었습니다. 정확한 정의보다 처음 읽을 때 막히지 않는 것을 목표로 썼습니다.

## POI 가 쓰는 말

| 말 | 뜻 |
|---|---|
| 결정 | 이 제품이 기록하는 한 건. 「무엇을 볼지」와 「어떻게 되리라 보는지」를 담는다 |
| 커밋 | 결정을 온체인에 올리는 것. 본문은 해시로만 올라가고, 관측 조건과 구간은 평문으로 남는다 |
| 관측 구간 | 결과를 판정할 시간 범위. 커밋할 때 미리 선언하고, 나중에 바꿀 수 없다 |
| 정산 (결과 등록) | 구간이 끝난 뒤 관측값을 올리는 것. 그 값으로 맞았는지를 컨트랙트가 계산한다 (관측값 자체의 진실성은 보장하지 않는다) |
| 이의 | 제3자가 「그 관측값은 틀렸다」고 온체인에 남기는 기록 |
| 인장 | 화면에 찍히는 상태 도장. 대기 · 관측중 · 등록대기 · 기한초과 · 등록완료 등 |
| 기한초과 (`OVERDUE`) | 결과를 올려야 할 기한이 지났는데 안 올린 상태. **숨기지 않고 드러낸다** |
| 유예 (`graceSeconds`) | 구간이 끝난 뒤 결과 등록을 기다려 주는 시간. 이 시간이 지나면 기한초과가 된다 |
| 공개 (Reveal) | 감춰 뒀던 원문을 나중에 내놓는 것. 그래야 제3자가 해시와 대조할 수 있다 |
| 지표 | 무엇을 관측할지 정의한 것. 계산식·데이터 출처·간격이 문서에 적혀 있다 |
| 불변식 (`I1`~`I19`) | 컨트랙트가 반드시 지키게 만드는 규칙. 어기면 거래 자체가 되돌아간다 |

## 암호·기술 용어

| 말 | 뜻 |
|---|---|
| 해시 | 어떤 값을 고정 길이 문자열로 바꾸는 계산. 원본이 1비트만 달라도 결과가 완전히 달라지고, 결과에서 원본을 되돌릴 수 없다 |
| commitment | 원문을 감춘 채 「이걸 그때 정했다」만 남기는 해시. 나중에 원문을 내면 대조할 수 있다 |
| salt | commitment 를 만들 때 섞는 난수. 같은 내용이라도 결과가 달라져 남이 추측할 수 없게 만든다. **잃으면 공개가 영구히 불가능하다** |
| 프리이미지 | 어떤 해시의 원본이 되는 값. 「이 원문이 그 해시의 프리이미지다」 = 「이 원문을 해시하면 그 값이 나온다」 |
| 머클 증명 | 전체를 공개하지 않고 「이 값이 그 안에 있다」만 증명하는 방법 |
| 영지식 증명 (ZK) | 값 자체를 밝히지 않고 「조건을 만족한다」만 증명하는 방법 |
| 술어 / predicate | 참·거짓을 가리는 조건식. POI 에서는 `지표 · 부등호 · 기준값` 세 가지다 |
| JCS | JSON 을 항상 같은 모양으로 정리하는 표준(RFC 8785). 같은 내용이면 같은 해시가 나오게 하려고 쓴다 |
| frozen | 한 번 정하면 바꿀 수 없게 잠근 상태 |

## 온체인 용어

| 말 | 뜻 |
|---|---|
| EAS | Ethereum Attestation Service. 「누가 무엇을 언제 증명했다」를 남기는 표준으로, GIWA 에 기본 탑재돼 있다 |
| attestation | EAS 에 남는 기록 한 건. POI 의 결정·정산·이의가 전부 attestation 이다 |
| 스키마 | attestation 에 어떤 필드가 들어가는지 정한 틀. `schemaUID` 로 구별한다 |
| 리졸버 (resolver) | attestation 이 발행될 때 끼어들어 검사하는 컨트랙트. **POI 의 불변식은 여기서 강제된다** |
| UID | attestation 하나를 가리키는 고유 번호 (`0x…` 64자리) |
| `refUID` | 다른 attestation 을 가리키는 참조 필드. 결정끼리 이어 붙일 때 쓴다 |
| fixture | 화면에서 볼 수 있게 미리 만들어 둔 실제 기록. 가짜 데이터가 아니라 **진짜 온체인 기록**이다 |
| `MATCH` | 검증기 판정값. 온체인에 적힌 정산과 재계산 결과가 같다는 뜻 |

## GIWA 생태계

| 말 | 뜻 |
|---|---|
| 도장 | GIWA 의 온체인 신원 인증. 「이 지갑은 검증됐다」를 발급자가 증명한다 |
| Verified Address | 도장이 발급하는 「검증된 지갑」 증명. POI 는 이걸 결정에 붙여 「누가 말했는가」를 남긴다 |
| Verified Balance | 발행자가 검증한 특정 시점의 잔고를 증명하는 도장 기능. **잔고 값 자체는 공개된다** (스키마에 `uint256 balance` 평문). POI 는 아직 쓰지 않는다 |
| up.id | GIWA 의 온체인 아이디 |
| 보자기 | GIWA 의 영지식 증명 기술. 아직 개발자 문서가 공개되지 않았다 |
| `ORACLE_VERIFIED` | 관측값을 제3자 오라클이 독립 증명했을 때 붙을 등급. **아직 없다** |

## 등급 — 두 축으로 읽는다

POI 는 「얼마나 믿을 만한가」를 하나로 뭉치지 않습니다. 질문이 둘이기 때문입니다.

| 축 | 값 | 뜻 |
|---|---|---|
| 누가 말했나 | `SELF_DECLARED` | 발행자가 스스로 낸 것 |
| | `VERIFIED_ADDRESS` | 도장으로 검증된 지갑이 낸 것 |
| 내용이 공개됐나 | `SEALED` | 아직 해시만 있다 |
| | `REVEALED` | 원문이 공개돼 대조 가능하다 |

하나로 합치면 화면이 사실보다 강한 말을 하게 됩니다.
