## 읽는 법

* **구현** — 코드가 있고 테스트가 있다
* 배포 — GIWA Sepolia에 올라가 있다
* fixture — 그 상태의 실제 attestation이 체인에 있어 화면에서 볼 수 있다
* 공개 검증 — 제3자가 지갑 없이 직접 확인할 수 있다

`❌ fixture` 는 **기능이 없다는 뜻이 아니라 데모에 실제 사례를 만들지 않았다는 뜻**입니다.
지금 남은 `❌` 는 CT18 복사 공격 하나뿐입니다 (아래 참고).

노트 승격 · Decision Graph · 도장 검증 스냅샷은 **테스트넷에 실제 attestation 이 있습니다**:

| | UID |
|---|---|
| 노트 | `0x95692da63de1f89b5973c8ce67698e4d757254812dfb6f500727d76b46b911da` |
| 부모 결정 (노트 승격) | `0xe015bb0a57ef32f7fa579a0ed7951555405ea6febdbe63fb4ceece0e468786db` |
| 자식 결정 (부모 참조) | `0x5d2a066cec47c29327e955c11a46ca028fe8a8ecda62cffc8b29bf4441570606` |
| 도장 검증 스냅샷을 붙인 결정 | `0x3f592f21a7e5a733d3dd90caeb2f9ec35bffa335b69da7310749694283e16938` (「도장 검증 — TESTNET FAUCET」) |

검증 스냅샷은 **TESTNET FAUCET 발급분**입니다. 업비트 KYC 발급 경로는 같은 컨트랙트
검사를 타지만 **저희가 직접 받아 본 적은 없습니다** — 발급자 라벨로 둘을 구별해 표시합니다.

## 운영 상태

| | |
|---|---|
| 소유권 | **2-of-2 Safe** `0x215253B8…DCE1` 로 이전 완료 (2026-07-30). `pendingOwner` 는 0 입니다 |
| `renounce` · `sealRegistry` | 하지 않습니다 — Phase 1 지표 추가가 필요합니다 |
| 실사용자 | **없습니다.** 지금 온체인에 있는 것은 데모 fixture입니다 |
| 사용자 수·활성도 | 제시하지 않습니다 |

리졸버·스키마·지표 UID 는 [배포된 주소와 UID](../intro/deployed.md)에 있습니다.

> **CT18 복사 공격 fixture 는 테스트넷에 없습니다.** 로컬 시드(`scripts/dev_up.sh`)와
> E2E 에는 있지만, 공개 테스트넷에 "남의 commitment 를 복사한 결정"을 영구히 남기는 것이
> 적절하지 않다고 판단했습니다. 원리는 [commitment 설계](../design/commitment.md)에서
> 확인할 수 있고, 로컬에서 재현할 수 있습니다.
