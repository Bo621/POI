## 읽는 법

* **구현** — 코드가 있고 테스트가 있다
* **배포** — GIWA Sepolia에 올라가 있다
* **fixture** — 그 상태의 실제 attestation이 체인에 있어 화면에서 볼 수 있다
* **공개 검증** — 제3자가 지갑 없이 직접 확인할 수 있다

`❌ fixture` 는 **기능이 없다는 뜻이 아니라 데모에 실제 사례를 만들지 않았다는 뜻**입니다.
Decision Graph와 노트 승격은 테스트에서 검증되지만 테스트넷에 예시가 없습니다.

## 운영 상태

| | |
|---|---|
| 소유권 | **아직 배포 지갑**에 있습니다. multisig 이전 전입니다 |
| `renounce` | 하지 않습니다 — Phase 1 지표 추가가 필요합니다 |
| 실사용자 | **없습니다.** 지금 온체인에 있는 것은 데모 fixture입니다 |
| 사용자 수·활성도 | 제시하지 않습니다 |

fixture UID 전체는 [배포된 주소와 UID](../intro/deployed.md)에 있습니다.

> **CT18 복사 공격 fixture 는 테스트넷에 없습니다.** 로컬 시드(`scripts/dev_up.sh`)와
> E2E 에는 있지만, 공개 테스트넷에 "남의 commitment 를 복사한 결정"을 영구히 남기는 것이
> 적절하지 않다고 판단했습니다. 원리는 [commitment 설계](../design/commitment.md)에서
> 확인할 수 있고, 로컬에서 재현할 수 있습니다.
